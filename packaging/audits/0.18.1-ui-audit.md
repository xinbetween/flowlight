# Flowlight 0.18.1 UI and accessibility audit

- Date: November 12, 2026
- Candidates: Developer and Mac App Store editions 0.18.1 (85)
- Minimum window: 1000 × 660 points

## Result

The final 0.18.1 source candidates pass the 1,259-test Developer suite, 32-test Store-hosted suite, Developer and Store static analysis, localization parity, generated-project drift, first-party Swift warning, release-helper, and generated-site gates. The complete graph, database, lineage, and demo coverage passes after the final gateway-routing and README follow-up. The Developer candidate was rebuilt and launched through the isolated demo workflow, verified to open only `demo.sqlite`, and visually inspected on Policies, the closed-main-window update warning, and the complete obstacle-clear AI gateway route.

Signed extension-upgrade acceptance and the geometry UI-test execution remain release gates. The focused macOS UI-test target compiles and is now required by the newest-Xcode CI gate, but Xcode 27.2 on this machine rejects its locally ad-hoc-signed bundle before any test method starts because the copied platform runner and mapped non-platform bundle have incompatible signing identities. No UI-test interaction result is claimed from those local attempts.

## Blocking release acceptance

- Run `Flowlight UI Tests` on a host where the signed XCTest runner can establish its macOS automation connection, and retain the passing result for trailing-blank-area clicks and independent nested controls.
- Install the exact signed 0.18.1 Developer candidate over 0.18.0 while the old extension remains active. Verify the immediate warning, exact `0.18.0/84 → 0.18.1/85` identity, fail-open enforcement, one-dialog-per-session behavior, persistent Sources guidance, reinstall recovery, and restart fallback.
- Archive the Store product from the exact reviewed commit only after the 0.18.0 review state permits it. Verify signed host/extension identity and effective entitlements without locally re-signing the Store product.
- Install the exact TestFlight build and repeat filter health, attribution, inspection, certificate, proxy, Policies, cleanup, and no-camera-prompt acceptance before submission.

## Limits

- The local Store suite validates the Store compilation and hosted behavior but does not prove protected distribution entitlements or a working signed content-filter connection.
- The local Xcode 27.2 UI runner failed to load the test bundle because its platform/non-platform signing identities were incompatible. It occurred before any test method began and therefore neither passes nor fails the coordinate interaction assertions; the required pinned macOS 15 CI lane remains authoritative for that suite.
- No App Store Connect metadata, build selection, archive upload, or review submission was changed during this audit.
