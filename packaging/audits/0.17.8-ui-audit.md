# Flowlight 0.17.8 UI and accessibility audit

- Date: November 5, 2026
- Candidate: Developer edition 0.17.8 (82)
- Minimum window: 1000 × 660 points

## Result

No release-blocking UI or accessibility defect was found in the consolidated 0.17.8 candidate. The audit covered the release's changed navigation, Live chart, agent inventory, alert triage, Policies, Sources, Inspect-owned Plugins & Providers, reduced-motion handling, localization, and Store product boundary.

## Automated gates

- Complete macOS suite: 1,218 tests, zero failures.
- Swift warning gate: no first-party warnings.
- Performance budgets: startup, 600-edge graph, 10,001-row History query, 10,000-alert query, 1,000-agent inventory, and 5,000 × 6 plugin evaluation all pass; the gate's 101 ms / 100 ms fixture proves rejection.
- Chart palette: executable light/dark contrast, chroma, normal-vision, protan, and deutan checks pass; adversarial fixtures pass.
- Localization: source extraction, strict parity, placeholders, ordering, and `plutil` validation pass.
- Developer and unsigned Store product graphs compile independently.

## Limits and deferred work

- System Events did not expose the candidate window to this shell, so no manual AX click script is claimed. Keyboard, focus, labels, values, and ordering were instead checked through source inspection and the passing native suites.
- Signed Store entitlements were not exercised locally. The product was not re-signed; signed entitlement validation remains an authorized archive/CI gate.
- Temporary acceptance images were synthetic demo evidence only. They are not website or App Store assets and are not committed.
- Store screenshots, metadata, upload, build selection, and App Review submission remain deferred to 0.18.0.
