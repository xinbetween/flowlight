## App Review notes

Paste only after the signed uploaded build and the steps below have been repeated against that exact build:

> Flowlight has no account, login, subscription, or in-app purchase.
>
> HTTPS inspection is off by default. Certificate generation, TLS termination, decryption, and recording occur on the Mac, and Flowlight sends no inspection data to the Flowlight developer. Inspection-derived content leaves the Mac only when the user explicitly invokes provider-backed Ask, exports data, or directs a proxied request to its intended external destination. In the Mac App Store build, Flowlight does not change system proxy settings, trust settings, or another application’s files, preferences, launch state, or proxy configuration. It does not relaunch or supervise other apps.
>
> To review HTTPS inspection on macOS 15 or later:
>
> 1. Open Sources › Collector and enable the Flowlight content filter. If approval is required, open System Settings › General › Login Items & Extensions › Network Extensions, enable Flowlight, return to Flowlight, and press Refresh. Sources must report **Data is arriving** before continuing.
> 2. Open Inspect and turn on HTTPS inspection. Flowlight creates a Keychain-backed P-256 certificate authority and starts a loopback HTTP/HTTPS proxy. Setup must show **Trusted app attribution** as available before app-scoped policy is tested. If Flowlight detects an inherited Developer proxy configuration, follow its System Settings remediation first; the Store build reports that state but never changes it.
> 3. In Inspect › Advanced, use Show Certificate in Finder. Open the exported public certificate in Keychain Access, add it to the login keychain, open its Trust section, and explicitly set Secure Sockets Layer (SSL) to Always Trust. The certificate name begins **Flowlight Inspection CA**; its private key never leaves Flowlight’s Keychain access group.
> 4. Use Copy Proxy Address and note the displayed `127.0.0.1` port. Open System Settings › Network › the active interface › Details › Proxies. Set both Web Proxy (HTTP) and Secure Web Proxy (HTTPS) to `127.0.0.1` and that port. This is a reviewer-controlled macOS setting; Flowlight deliberately does not perform this step.
> 5. Open Safari and load `https://example.com/`. In Flowlight, open the resulting Inspect row and verify **Source App** is Safari (`com.apple.Safari`), **Host** is `example.com`, and the request shows its method, status, timing, and retained redacted headers/body. Supported AI traffic also shows extracted tool-call attribution.
> 6. Mock responses and request rewrites are available for requests explicitly routed through this loopback proxy. Response-transform scripts and executable script plugins are intentionally unavailable in the Store product.
> 7. After testing, turn off both proxy switches in System Settings and restore any values that were present before the test. Use Remove Certificate & Recorded Data in Flowlight, then delete the matching **Flowlight Inspection CA** public certificate from the login keychain. Confirm `https://example.com/` loads normally in Safari with Flowlight closed.
>
> The content-filter extension identifies the exact live loopback client flow from the audit token supplied by macOS and matches the client source address, client source port, and active proxy port. Setup reports ready only after the exact extension version accepts the durable-event protocol, macOS reports the filter running, and the extension acknowledges that listener port. Unknown, stale, mismatched, or ambiguous identity fails open for app-scoped enforcement; Flowlight never guesses an application identity. Destination-only rules and all-app managed packs still apply without identity.
>
> Remove Certificate & Recorded Data deletes Flowlight-owned private keys, generated leaf certificates, and recorded requests. A public CA imported by the reviewer remains user-owned and must be removed separately in Keychain Access; the UI states this before removal. The reviewer must also restore the HTTP/HTTPS proxy settings they changed manually.
>
> Flowlight uses `com.apple.security.device.camera` only to enumerate camera devices with CoreMediaIO and read `kCMIODevicePropertyDeviceIsRunningSomewhere`. It never opens a capture session, requests camera capture access, or reads frames; the signed-build test must confirm that no camera TCC prompt appears.
