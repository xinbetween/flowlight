### What's new in 0.4.1

**A fix: the Rules screen came up blank.**

From 0.3.5 to 0.4.0, opening **Rules** (⌘5) emptied the window — no list, no sidebar, nothing. The rule engine itself was working the whole time: rules were being carried out, refusals were recorded, and the alerts about them were correct. The screen that shows them wasn't.

The cause was a hand-rolled header and empty state laid out in a way SwiftUI couldn't resolve. The screen has been rebuilt in the same shape every other screen in Flowlight uses — a navigation title, its controls in the toolbar, and `ContentUnavailableView` for the empty state — which is both what works and what looks like the rest of the app.

Also fixed: **a window that had been nudged off the edge of the screen came back that way, every launch.** The check asked whether the saved frame overlapped a screen at all, which is true of a window hanging most of the way off the right edge. It is fitted back inside the visible area now — moved when it only needs moving, so a window you sized deliberately keeps its size.

No other changes. Peer-to-peer Wi-Fi from 0.4.0 is unaffected.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.4.1.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
