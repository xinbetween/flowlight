### What's new in 0.6.0

**Ask answers more, and shows its working better. Rules looks like a designed screen.**

#### Ask

- **It answers questions about Flowlight itself.** *How do I turn on HTTPS inspection?* *How do I stop an agent using its shell tool?* *Why am I not seeing any traffic?* Those come from the app's own written-down guide to all eighteen features — what each one is, the steps to switch it on, where it lives, and what it can't do — together with a snapshot of how this Mac is currently set up. Never from the model's memory: menu paths differ between versions, and an invented one is worse than no answer. When an answer needs a switch changed it says where the switch is and offers to open that screen, which is a click you make.
- **Charts when the shape matters.** A line for change over time, bars to compare, a pie for a split of one whole. Flowlight draws them from the same rows the query returned, so the picture and the sentence cannot disagree — and the model can ask for a different shape, or for none.
- **Twelve suggested questions** instead of three, covering both traffic and configuration, in a row beside the field where you look when you don't know what to type.
- **The panel is rebuilt.** The composer was floating at two-thirds height over a void with a field seventeen hundred points wide; it is pinned to the bottom now, on a readable measure. The queries behind an answer collapse to one line that expands, rather than a wall of monospace competing with the answer itself.

#### Rules

Rules are grouped into **in force** and **not in force**, so the first question you have is answered before you read a word. Each rule is a card read top-down: what it does in plain words with the parts it names in monospace, then the bookkeeping. A rule the current engine can't carry out now changes its own icon from a red hand to an orange eye and carries an inset strip saying so — it should never look like it is refusing something when it isn't. The violations feed is grouped by day instead of being a spreadsheet, and the editor leads with the rule read back as a sentence.

Capture and Devices were brought into the same language.

#### Movement

One vocabulary rather than ad-hoc timings. Answers and rows rise in; totals count to their new value; the capture dot breathes while data is actually arriving, because a still green dot and a live one look identical in a screenshot. Nothing moves layout under the pointer, and all of it stops when the system is set to Reduce Motion.

#### Fixed

A model declining a chart with `chart: "none"` had that chart handed straight back to it — "none" means *unset* for an app name but is a real value for a chart.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.6.0.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel. The on-device model for Ask needs macOS 26; every other provider works without it.
