### What's new in 0.16.4

- **See the real proxy chain.** AI activity now combines each agent’s documented gateway setting with captured socket and inspection evidence, showing configured agent → gateway, observed gateway → Flowlight, and Flowlight → destination stages without claiming configuration is observed traffic.
- **Recognize local gateways by the process that owns them.** Flowlight reads documented Claude Code, Codex, Gemini CLI, Cursor, Windsurf, and Zed settings, stores only a sanitized scheme, host, and port, and resolves localhost listeners to the actual application icon and identity instead of assuming a product or port.
- **Read volume from every observed route segment.** Ribbon width reflects total received plus sent bytes in the selected period—including GB-scale traffic—while counters remain attached exactly once; configured-only relationships stay thin and carry no particles.
- **Keep selection and roles unambiguous.** Hover can no longer make an unrelated edge look selected, launcher, agent, and proxy cards expose their roles, and application-backed proxies use their own icon across Map, List, inspector, keyboard, and VoiceOver paths.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.16.4.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
