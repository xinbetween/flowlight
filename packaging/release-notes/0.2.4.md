### What's new in 0.2.4

- **Fixed: switching the capture source froze Flowlight.** Choosing the Network Extension while the nettop sampler was running could beachball the app for minutes. Closing the packet-capture device waits for the reader to let go, and the reader had no timeout, so on a quiet network it waited for the next packet — with the whole app behind it. Reported by a user, with a hang report that pointed straight at it.

- **Inspect now tells you when it isn't working.** Turning HTTPS inspection on used to report success as soon as the system-proxy commands ran, so a listener that never started, a proxy setting that didn't take, or a Mac with no network services all ended up looking the same: enabled, and inspecting nothing. Flowlight checks the three things that have to hold — the proxy is listening, every network service points at it, the settings file is actually being served — and says which one doesn't. There's a **Check Setup** button on the Inspect screen.

- **Search inside request and response bodies.** The Inspect search covered hosts, paths, apps and tool names; it now reads the bodies too, so a model name, a tool argument or an id that only appears in a payload finds its exchange. Matching lines are highlighted in the body, with a count and a jump to the raw view where the highlighting shows.

- The Inspect empty state now explains the thing that surprises people: browsers and most Mac apps are inspected automatically, while command-line agents need the environment from an inspected Terminal.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.2.4.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
