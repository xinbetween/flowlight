### What's new in 0.16.5

- **Make the graph agree with Reports.** Traffic mode now chooses applications by their full selected-period received plus sent bytes, guarantees each selected application a representative relationship, and keeps the application card total complete when quieter relationships are hidden.
- **Keep routed and owned traffic distinct.** Flowlight’s application card reports traffic owned by Flowlight, while the separate Flowlight proxy card reports traffic routed through inspection; relationship ribbons still count every byte exactly once.
- **Keep bare addresses exact.** Blocked IPv4 and IPv6 destinations now converge with observed traffic on one destination node and carry exact address-scoped Reports and rule actions instead of fabricated domain families.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.16.5.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
