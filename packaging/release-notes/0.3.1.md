### What's new in 0.3.1

- **Mock responses.** Answer a chosen host, path and method with your own status, headers, body and delay, to see how an agent copes when an API fails, stalls, or returns something odd. The request is never sent — Flowlight answers it. Rules live in **Inspect › Mock responses**, are ordered so the first enabled match wins, and switch on and off individually. *Mock This Endpoint…* on any recorded exchange fills one in for you.

  Host matching is exact by default (`*.example.com` covers a domain and its subdomains), because a mock aimed at one endpoint shouldn't quietly answer for a whole domain. Paths take a single `*` wildcard.

- **A mocked exchange is unmistakable.** It's recorded like any other, marked **Mocked** in the list, and the detail pane says it was answered by Flowlight rather than by the host, naming the rule. Reading a session back later, you can always tell what was real. Active rules show as a count in the Inspect status bar, so a mock left on doesn't cost you an afternoon.

Two limits worth knowing. Only traffic Flowlight decrypts can be mocked, so the endpoint has to be going through HTTPS inspection — a rule for a host makes Flowlight decrypt that host even under the agents-only scope. And the destination is still connected to: a mock changes the answer, not whether the connection can be made, so "the API returns 500" works while "the API is entirely unreachable" does not.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.3.1.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
