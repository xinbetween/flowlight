### What's new in 0.18.0

- **Inspect HTTPS traffic from the Mac App Store edition.** The Store product gains its own sandbox-safe local inspection path, certificate lifecycle, onboarding and recovery without embedding the Developer system extension, response-script helper, privileged installer, `SystemExtensions.framework`, or `OSSystemExtension` symbols.
- **Understand every source in one place.** Sources adopts the same native segmented navigation as Policies, with focused Collector, Devices, and Coverage sections plus shared health and remediation context.
- **Keep every policy action and its evidence together.** Policies restores managed-pack activity actions, ordinary-activity copy and attribution, dropped-hit disclosure, pack counts and provenance, and an explicit active/resting organization while preserving every editor migrated from Rules.
- **See connections form and change.** Connections gains polished native graph motion and clearer relationship emphasis while preserving atomic generation commits, stable geometry, keyboard and VoiceOver meaning, reduced-motion behavior, and measured rendering budgets.
- **Pause all network enforcement truthfully.** Pause Blocking now stands down ordinary destination rules, enforcing allowlists, extension-managed packs, and inspection-proxy pack decisions together. Inspection policies such as guardrails remain separate and keep their own visible status.
- **Carry the completed unpublished work forward.** The unpublished 0.17.4 through 0.17.9 changes ship here, including AI-agent inventory, alert triage, inspection providers, accessible Live charts, exact-evidence CI reuse, immutable prepared release bytes, and credential-free publication.
- **Keep Developer ID and Store products honest.** The Store edition uses explicit proxy routing and user-mediated certificate trust, and omits system-proxy automation, external-app rewrites, response transforms, and script plugins. First Store launch keeps Store inspection off, ignores but preserves Developer routing metadata, moves to a Store-specific port, and reports old proxy routing for manual remediation without changing it. Setup reports ready only after trusted content-filter attribution is available. The direct edition retains its automation; separate build, entitlement, and bundle gates enforce the boundary. Both apps and both embedded filters share the reviewed 0.18.0 (84) identity; the direct upgrade replaces the system extension and macOS may request one restart while retiring the previous copy.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.18.0.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
