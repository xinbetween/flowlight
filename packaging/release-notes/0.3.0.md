### What's new in 0.3.0

**Flowlight can now refuse a connection, not only report it.** This is the first thing it does that changes traffic rather than watching it, so it is off unless you ask for it, per agent.

- **Refuse connections outside the list.** A per-agent switch beside the allowlist. With it on, a connection to somewhere not on the list is dropped, and an alert records what was refused — with **Allow … from Now On**, which adds that exact destination to the list in one click. The agent's next attempt goes through.

- **It stays off for lists you already have.** An allowlist written before this release keeps warning and nothing else. A tool people leave running shouldn't change what it does to their network because they installed an update.

- **Things that are never refused**, whatever a list says: your local network, DNS, Apple's own services, and Flowlight's own traffic. Where there is doubt the connection is allowed and recorded — a blocked Mac is a worse outcome than a blocked agent.

- **Enforcement lapses a few seconds after Flowlight stops running.** A refusal nobody can see is worse than no refusal, and undoing one lives in the app.

- **It needs the Network Extension.** Refusing a connection means sitting in its path, which the nettop sampler can't do. Capture says so rather than offering a switch that does nothing.

Two things it doesn't do. HTTPS inspection and blocking don't combine — traffic through Flowlight's proxy leaves as Flowlight's own, which is never refused. And there's no "allow once" prompt: holding a connection open while waiting for someone who may be away from their desk is the one thing a network monitor must never do, so it refuses and offers the one-click undo instead.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.3.0.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
