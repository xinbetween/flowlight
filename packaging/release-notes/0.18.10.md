### What's new in 0.18.10

- **Identify executable versions on demand.** Advisories now offers a visible page-level action that can run bounded `--version` checks for supported local tools such as curl, git, node, Python, and wget.
- **Keep execution explicit and local.** Metadata-only inventory scanning remains automatic; executable checks require the Advisories action, use fixed arguments and canonical paths, and never upload inventory or probe output.
- **Keep probing safe and bounded.** Checks use empty environments, null stdin, strict output limits, short timeouts, cancellation, process-group cleanup, and conservative parsing. Unsupported or uncertain tools remain visibly unknown.
- **Show evidence clearly.** Successful results are labeled as executable version output without changing advisory identity, enforcement, policy scope, or network behavior.
