### What's new in 0.5.0

**Ask Flowlight.**

Ask in plain language and get an answer from the history on this Mac. *What did Claude Code upload yesterday?* *Which app started talking to somewhere new this week?* *Summarise the last hour.*

**The model never gets your history.** It is handed a list of seven read-only queries it may call — totals, top apps, top destinations, new destinations, alerts, agents, and a series over time — and nothing else. There is no query that takes SQL, and there will not be one: a model that can write its own query can read anything, and then the promise stops being true the first time someone is clever. Flowlight runs whichever query the model names, here, and hands back the totals and names.

- **Local first.** Where macOS provides an on-device model, that's the default: it costs nothing, works offline, and sends not one byte anywhere. Otherwise a model server you already run — Ollama, LM Studio, llama.cpp. Both sit above the hosted options, because a tool whose promise is no account and no cloud shouldn't need either to answer a question about itself.
- **Or bring your own key** for Anthropic, OpenAI, Gemini or any OpenAI-compatible endpoint. Your key goes to your login Keychain, not to Flowlight's preferences. The screen says *before* you ask whether the question will leave the Mac, and **every request is shown in full under the answer**.
- **Every query is listed under the answer**, with what it found, and clicking one opens those rows in Reports. An answer you can't check is a guess with better grammar.
- **Flowlight holds itself to its own standard.** Whatever Ask sends shows up in Live and Reports like any other app's traffic — including when the model server is on this same Mac, which is the case it would have been easiest to leave out.

Windows are resolved here, not by the model: it proposes *24h* or *yesterday*, and this Mac decides what that means, in its own time zone, bounded to a year.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.5.0.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel. The on-device model needs macOS 26; everything else works without it.
