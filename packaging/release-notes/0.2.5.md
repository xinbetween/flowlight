### What's new in 0.2.5

**If you use the Network Extension, this release is the one that makes it work after an update.**

- **Fixed: the filter stopped working after every app update.** macOS keeps running whichever build of the system extension was last activated, so after Flowlight updated itself the extension was still the previous version — and macOS refuses the connection between a mismatched pair. Capture said *"Extension unreachable: Couldn't communicate with a helper application"* next to an extension that was plainly installed and enabled, and the only cure was knowing to press **Install & enable filter** again. Flowlight now checks the installed version at launch and re-activates the filter itself when it doesn't match.

- **Fixed: a working extension could report itself as unreachable indefinitely.** Each reconnection attempt left the previous one alive, so an old connection failing would overwrite the status and tear down the connection that was actually working. Attempts are now tied to the connection they came from, and anything superseded is ignored.

- **Fixed: the status went amber whenever the network was quiet.** The extension only sends when there is traffic, and a quiet second was being read as "not receiving". It now reports that it is alive between bursts, the way the sampler always has.

- **Refresh, in Capture, now reconnects to the extension** as well as re-reading its settings — so there's a way to retry that isn't relaunching the app.

- **Capture explains what each engine can miss.** The sampler compares running counters, so a long transfer is counted exactly however bursty it was; what it loses is a connection that opens *and* closes between two readings. The extension is called as each connection is made and sees those. [The full comparison is in the docs](https://flowlight.xinbetween.com/docs/#engines).

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.2.5.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
