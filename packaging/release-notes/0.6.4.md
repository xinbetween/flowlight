### What's new in 0.6.4

**Meta's AI is recognised, Muse included.**

`muse.ai` answers from Meta's own network — the same address as `ai.meta.com` and `api.llama.com` — so Muse, Meta AI and Llama are one ecosystem rather than three vendors, and Flowlight now names all three:

- **Meta Muse** — `muse.ai`
- **Meta AI** — `meta.ai`, `ai.meta.com`
- **Meta Llama** — `llama.com`, `llama.developer.meta.com`

An app that talks to any of them counts as an AI agent, the same as one talking to Anthropic or OpenAI. That brings the number of LLM API providers Flowlight knows to 27.

**What is deliberately left out.** `meta.com`, `facebook.com`, `fbcdn.net` and the rest carry Facebook, Instagram and WhatsApp. Matching those would file a scroll through Instagram as AI traffic, and a column that cries wolf about half a Mac's traffic is worse than no column. Meta's network is also kept out of the owner-matching used for traffic with no hostname, for the same reason — that shortcut works for Anthropic and OpenAI only because they serve nothing else.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.6.4.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
