### What's new in 0.3.3

The last of the "get out of the way" work. The menu-bar-only mode arrived in 0.2.7; this finishes the rest.

- **The window reopens where you left it**, at the size you left it. A first run still fills the screen so nothing is hidden behind a small default window, and a window whose saved position is off-screen — an unplugged display — comes back on the screen you actually have.

- **A first run no longer opens with a request for your password.** Hostname setup is offered a little after launch, and only while a window is open. Asking for an administrator password over whatever someone happens to be doing, possibly at a window they don't have open, is how a monitor gets quit instead of set up. The offer keeps: it returns next launch until taken or dismissed.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.3.3.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
