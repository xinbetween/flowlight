### What's new in 0.16.6

- **See every relationship.** Map stays readable with a bounded projection, while List retains the complete semantic graph and reveals it 25 relationships at a time without changing Map layout.
- **Render each application once.** Flowlight and other application-backed agent, tool, launcher, gateway, and proxy roles converge on one card while exact role evidence, members, and traffic accounting remain intact.
- **Find quiet evidence exactly.** Search and Focus apply before Map projection across application, destination, owner, agent, MCP, launcher, route, gateway, and enforcement evidence, so relationships omitted from Map remain discoverable.
- **Make “Show 25 more” immediate.** Reports updates its page limit and displayed tree in the same action instead of waiting for a later view callback.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.16.6.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
