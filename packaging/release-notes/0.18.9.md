### What's new in 0.18.9

- **Inventory more than application bundles.** Advisories now discovers accessible applications, standalone executables such as curl and wget, Homebrew formulae and casks, and npm packages under project folders you explicitly select.
- **Keep software identity typed and evidence-based.** Executables, Homebrew artifacts, applications, and npm packages remain separate identities; versions come from Info.plist, Homebrew receipts, or package manifests rather than filenames, paths, or arbitrary binary execution.
- **Keep package discovery bounded.** Standard locations are scanned without a home-directory crawl, selected folders use depth, visit, size, symlink, and permission boundaries, and incomplete sources remain visible.
- **Keep matching local and conservative.** Signed catalog targets are kind-qualified, npm versions use strict semver boundaries, legacy bundle-ID advisories remain compatible, and no advisory result changes traffic enforcement.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.18.9.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
