### What's new in 0.18.7

- **Recover cleanly after upgrades.** When macOS keeps older Network Extension copies waiting for reboot, Flowlight now recognizes the held filter during reconnect and opens the existing recovery dialog instead of looping on “Extension connection invalidated.”
- **Ask for the right action.** The recovery dialog explains that restarting the Mac finishes the update and keeps the reinstall alternative available when a restart is not convenient.
- **Keep startup quiet.** Held-copy evidence discovered during a healthy launch does not interrupt the user; the recovery dialog appears only after the selected Network Extension actually becomes unavailable.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.18.7.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
