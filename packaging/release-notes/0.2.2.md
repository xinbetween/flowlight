### What's new in 0.2.2

- **Focus mode.** Pick a few apps and destinations and every screen shows only those — Live, Reports, Alerts, AI Agents and Inspect, plus the menu bar rates. Right-click a row in any table to focus on it, or use the Focus control at the bottom of the sidebar; ⇧⌘F turns it on and off.

  It filters what you see and never what's recorded: Flowlight keeps capturing everything while Focus is on and the anomaly baselines keep learning from all of it, so turning it off shows the traffic it was hiding. [How it works](https://flowlight.xinbetween.com/docs/#focus)

- **Install with Homebrew** (new in 0.2.1):

  ```
  brew install --cask xinbetween/tap/flowlight
  ```

  The same command upgrades it later.

Two limits worth knowing: an alert records the app that raised it and not the destination, so focusing only on destinations leaves the alert list alone; and IP ranges like `10.0.0.0/8` aren't accepted as Focus targets — single addresses and domains are.

### Install

Signed with Developer ID and notarized by Apple, so macOS opens it without the "unverified developer" wall.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.2.2.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
