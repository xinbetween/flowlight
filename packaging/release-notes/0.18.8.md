### What's new in 0.18.8

- **Inspect the app you just saw.** Live now offers a discoverable app inspection action and carries the exact bundle ID into Inspect instead of turning a display name into a broad body search.
- **Keep the investigation window bounded.** Live opens Inspect over the last hour, with the selected window visible and editable in Inspect.
- **Read History in context.** History keeps the selected range, follow-now state, filter scope, and grouping visible while giving the breakdown table more room.
- **Make report evidence honest.** Hostname coverage is calculated for the selected report window and filters, and unknown or owner-less traffic remains explicitly unknown rather than being treated as safe.
- **Keep local risk useful without taking over the page.** The advisory status is compact when there are no actionable findings, while detailed medium/high and unassessed counts remain available when relevant.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.18.8.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
