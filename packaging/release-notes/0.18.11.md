### What's new in 0.18.11

- **Make advisory catalog availability verifiable.** Flowlight now ships the signed advisory catalog at the endpoint used by the app, so a missing public route no longer leaves every local artifact in the catalog-unavailable state.
- **Keep catalog trust unchanged.** The endpoint serves the exact signed envelope already bundled with Flowlight; catalog matching remains local, inventory is never uploaded, and signature, freshness, rollback, and recovery checks remain enforced.
- **Be clear about the initial catalog.** This release contains an intentionally empty signed catalog. It enables a verified catalog state but does not claim that software is safe or report CVEs until a separately reviewed and offline-signed advisory catalog with real records is published.
