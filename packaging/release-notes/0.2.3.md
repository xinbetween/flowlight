### What's new in 0.2.3

**Nothing, if you're using Flowlight.** The app is byte-for-byte the same as 0.2.2 — there's no reason to update for it.

This release exists to prove the new build pipeline. Releases are now built, tested, signed, notarized and published by [a GitHub Actions workflow](https://github.com/xinbetween/flowlight/blob/main/.github/workflows/release.yml) on a version tag, so they no longer depend on one Mac, and every release is reproducible from a tag rather than from someone's laptop.

For a tool that asks you to trust a signed binary, how that binary gets signed matters:

- The signing certificates live in a GitHub environment that requires a human approval, and that only accepts `v*` tags. A workflow added to a branch cannot reach them.
- Release tags are immutable — deletion, updates and force-pushes are blocked — so a published tag always points at the commit that was reviewed.
- Actions are pinned to commit SHAs, not moving tags.
- Every release is checked with `spctl` before it's published, and the checksums below come from the same run that built the artifacts.

It also found a real bug on the way in: the tests built DNS and TLS packets with expression chains that an older Swift compiler refuses to type-check, which never showed up on a newer one locally. CI now builds on both ends of the Xcode range Flowlight supports.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.2.3.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
