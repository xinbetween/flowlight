### What's new in 0.18.12

- **Review local agent settings in Advisories.** Advisories opens on the new Agent tab, which checks supported agent settings for permissions, instructions, hooks, plugins, skills, MCP servers, gateways, and provider configuration. The Software tab contains the package inventory and signed advisory matching.
- **Scan locally after one-time folder approval.** Agent Advisories automatically checks the home folder and remembers additional folders you choose. It skips protected locations and reports incomplete coverage. Apple's on-device model summarizes structured findings by default, and Inventory only keeps the same findings available without model analysis.
- **Keep AI Agents responsive under heavy traffic.** Traffic aggregation runs off the main thread, alert counts update independently, and destination details load as they come into view. Quiet agents remain visible beside busy agents, traffic totals remain complete when details are capped, and Tool calls can show linked requests from child processes. This addresses [issue #115](https://github.com/xinbetween/flowlight/issues/115).
- **Improve software version evidence.** Software Advisories can read additional executable metadata and compare supported Python and Go versions with their ecosystem-specific rules. It distinguishes a recorded version from one it can use for matching.
