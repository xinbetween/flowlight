### What's new in 0.2.6

**This release is about the Network Extension telling you the truth.** Two users reported it as broken when it was working, and one where it genuinely couldn't work and said nothing.

- **Flowlight now says when macOS won't let its filter run.** macOS allows **one content filter at a time**, and on a managed Mac a VPN or security agent usually has that slot. Flowlight's filter still installs, activates and connects — so everything looked healthy — while macOS never handed it a single connection and every screen stayed empty. Capture now lists the other content filters it finds, by name, explains that this is macOS's limit rather than anything Flowlight can work around, and offers a button to switch to the sampler, which needs no filter and runs alongside them.

- **Fixed: switching to the extension showed an empty Live panel.** The extension buffered everything it captured while no app was connected — the whole time the app was on the sampler — and then replayed up to an hour of it oldest-first. Every batch carried a timestamp from minutes ago, Live keeps two minutes, and anything current was queued behind the backlog. The buffer is five minutes now and drains at once.

- **"Connected" no longer implies "working".** Connecting to the extension proves the process is running, not that it is being given any traffic. The status says which of those is true.

- **A diagnostic you can run when capture misbehaves.** It reports state and counts — never anything Flowlight recorded about your traffic:

  ```
  curl -fsSL https://raw.githubusercontent.com/xinbetween/flowlight/main/scripts/diagnose.sh | zsh
  ```

  The filter also logs a count each minute — flows seen, statistics reports, batches sent — which separates "not being given anything to filter" from "can't deliver what it has".

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.2.6.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
