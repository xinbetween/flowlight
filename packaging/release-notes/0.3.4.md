### What's new in 0.3.4

**Focus is symmetric now: one app is a focus, and so is one destination.**

Before this, only destinations could be typed. Apps could be ticked off a list of whatever had been busy in the last day — so an app that had been quiet couldn't be focused at all, which is an odd gap in a feature for watching one thing closely.

- **Add an app by name or bundle identifier.** Every application on the Mac is searchable, so a quiet one works as well as a noisy one. A command-line agent with no application bundle — `claude`, `codex` — can be named directly, because refusing to focus on something you can name would be daft.
- **Either half alone is a complete focus.** The editor says so, rather than leaving you to guess whether you need one of each.
- **Alerts say why a destination-only focus doesn't narrow them.** An alert records the app that raised it and nothing about where the traffic went, so destinations have nothing to match on. The editor states it instead of letting a screen quietly ignore your focus.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.3.4.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
