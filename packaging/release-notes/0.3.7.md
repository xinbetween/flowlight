### What's new in 0.3.7

**The site says what the app now does, and reads like it.**

Nine releases landed since the site was laid out, and it had drifted — the comparison table still answered *Blocks connections* with "No, observe only", two lines under a lede saying Flowlight can refuse. This is a pass over every page that cuts rather than adds.

- **Counts come from the source at build time.** The home page claimed 25 LLM API providers; the docs said 24; `AgentCatalog` named 24. `build_site.py` now counts the providers, the agents and the alert kinds from the Swift that defines them, so the question stops recurring.
- **What changed in 0.3.0 through 0.3.6 is on the page.** Blocking is answered *yes*, with the engine it needs; the allowlist card says it can enforce; Rules and Guardrails have their own cards and their own docs sections; the roadmap lists only what hasn't shipped.
- **The two-column sections stay balanced.** A heading and a paragraph used to sit beside nine cards, leaving a tall column of nothing. The intro travels with the cards now, the way the docs table of contents already did.
- **Motion, sparingly.** Sections reveal as they come into view and cards lift under the pointer — opacity and transforms only, so nothing shifts the layout, and all of it off under `prefers-reduced-motion`.

No app changes in this release; the app is unchanged from 0.3.6 apart from its version.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.3.7.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.
