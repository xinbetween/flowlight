### What's new in 0.18.1

- **Keep Policies compact without hiding their state.** Network Rules, Agent Allowlists, and Managed Packs now fold independently and remember their state. Collapsed summaries keep in-force, reporting-only, enabled, and review-needed counts visible, while policy deep links expand their destination before opening it.
- **Use the whole row.** Policies section headers, ordinary-rule cards, managed-pack cards, and Official catalog details now respond across their full visible non-control area. Switches, menus, and Review remain independent controls with explicit keyboard and accessibility actions.
- **Explain a filter left behind by an update.** When exact extension registration proves that macOS is still running an older filter, Flowlight immediately identifies the running and expected builds, keeps enforcement fail-open, and offers product-specific reinstall, Capture settings, and restart guidance. The warning appears once per update incident even when the main window is closed and remains visible in Sources until the exact current filter is healthy.
- **Make reinstall outcomes truthful.** Store recovery now stops on preference-load/save failures. Developer recovery waits for deactivation, activation, approval, reboot, and filter-enable results instead of reporting success when the request merely started.
- **Show the route instead of a localhost dead end.** Connections now reconciles an exact configured local-gateway socket only when the listener identity, host, port, and downstream route all agree. The AI map preserves the full launcher → agent → gateway → Flowlight → destination chain, counts remote traffic once, and leaves unmatched localhost services visible.
- **Make the project front door useful again.** The README now follows a product-first quick-start structure with a visual architecture, supported-agent catalog, concise feature tour, documentation directory, privacy disclosure, roadmap, and build guidance.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.18.1.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
