### What's new in 0.17.4

- **See every control in Policies.** Rules is now a unified Policies inventory for ordinary rules, agent allowlists, managed packs, and Developer-only inspection policies, with truthful states such as enforcing, reporting, watching, waiting, scheduled, paused, applying, review required, or unavailable.
- **Keep each policy's real editor and evidence.** Selecting an item opens the contextual editor that owns it; Managed packs retain signer, publisher, catalog, version, and license provenance without weakening review or consent, while Activity combines existing records without pretending they share one persistence model.
- **Read Sources as one operational page.** Collector, Devices, and Coverage now flow in that order without a segmented control. Existing status links, Ask answers, restored windows, and screenshot arguments scroll to and briefly focus the requested section.
- **Dismiss chart details when the pointer leaves.** History no longer leaves a zero-value tooltip floating at the upper-left after the cursor exits the All traffic plot; keyboard bucket inspection remains unchanged.
- **Sign each release once.** The immutable tag run builds, signs, notarizes, Gatekeeper-verifies, attests, and retains one artifact; publication has no signing credentials and can only verify and publish those exact prepared bytes.

### Install

Signed with Developer ID and notarized by Apple.

- `brew install --cask xinbetween/tap/flowlight`
- `Flowlight.dmg` — drag to Applications.
- `Flowlight-0.17.4.pkg` — installs to /Applications; offers to quit a running copy first.

macOS 15 or later, Apple silicon and Intel.

Full changelog: https://github.com/xinbetween/flowlight/releases
