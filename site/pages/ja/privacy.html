デフォルトはローカル、例外はすべて明記

Flowlight にアカウントは不要で、プロダクト分析も含みません。トラフィックの記録はローカルに保存されます。このページでは、 アプリが何を記録するか、外部サービスに接続する任意の機能、そしてこれらの記述をソースコードで確かめる方法をまとめます。

要点

  • Flowlight は、ネットワークのメタデータ（どのアプリが、どのホストへ、どのポートで、何バイト、いつ）を、この Mac 上のデータベースに記録します。
  • パケットの中身を記録することはなく、トラフィックを復号することもありません。ただし、経由させるアプリについて任意の HTTPS インスペクションをオンにした場合は別です。
  • Flowlight はトラフィックのデータベースをアップロードせず、テレメトリ、クラッシュレポート、プロダクト分析も一切含みません。
  • アプリ自身が行う外部へのリクエストと、ユーザーが設定する書き出し先は、以下にまとめています。

記録する内容

1 秒ごとに、アプリ（バンドル ID、名前、実行ファイルのパス、プロセス ID）、リモートの IP アドレス、ホスト名、ポート、トランスポートと プロトコル、そして送受信したバイト数を記録します。上げたアラートと、異常検出のルールが使うアプリごとの基準値も保存します。 そのすべては ~/Library/Application Support/Flowlight にあります。

パケットキャプチャ

初回だけのホスト名セットアップを承認すると、Flowlight は主要なネットワークインターフェイスのパケットを、2 つのものだけを通すカーネルの フィルタ越しに読み取ります。DNS の応答と、TLS 接続の最初のメッセージ（ClientHello）です。そこから保持するのはホスト名と、それが対応する アドレスだけで、メモリ上にとどめます。ほかはすべてカーネルで捨てられ、パケットがディスクに書かれることはありません。

この Mac で読み取るもの

エージェントのツールと MCP サーバを結び付けるために、Flowlight は各プロセスの親とコマンドラインを macOS から読み取り、対応しているエージェントの MCP 設定ファイル（たとえば ~/.claude.json、~/.cursor/mcp.json、~/.codex/config.toml）を読み取ります。 保持するのは各サーバの名前、起動コマンド、URL だけで、メモリ上にとどめ、トラフィックと一緒に保存するのはその結果のラベル（「curl 経由」「github MCP」） だけです。これらのファイルやコマンドラインの内容が、どこかに送られることはありません。

HTTPS インスペクション

デフォルトではオフです。オンにすると、Flowlight はこの Mac 上に証明書認証局を作り（その鍵が ~/Library/Application Support/Flowlight/Inspection から出ることはありません）、この Mac からの接続だけを受け付けるプロキシを動かします。 経由させたアプリについては、リクエストとレスポンスを、2 MB までの本文も含めてローカルのデータベースに 3 日間記録します。認証情報のヘッダ （Authorization、Cookie、API キー）は、何かが保存される前にその長さに置き換えられます。Flowlight は内蔵の一覧にある Apple のサービスとパスワード管理アプリを復号の対象から除外します。記録したインスペクションのデータが Flowlight によってアップロードされることはありません。インスペクションをオフにするとプロキシが止まり、証明書と記録データを削除すると、証明書、その信頼設定、記録したすべてのリクエストが削除されます。

権限

  • 管理者パスワード（1 回だけ）。パケットキャプチャのアクセスのためです。キャプチャ画面から取り消せます。
  • 通知。警告のためです。任意です。
  • ログイン項目。「ログイン時に起動」をオンにした場合だけです。

保持期間

秒単位データは 6 時間（変更可能）、分単位データは 14 日、時間単位データは 400 日、日単位の合計は無期限、アラートは 90 日です。 キャプチャ › すべてのデータを消去でそのすべてを削除できます。~/Library/Application Support/Flowlight を削除しても同じです。

このウェブサイト

このサイトは GitHub Pages で公開され、Cloudflare を通して配信される静的なページです。Cookie は設定せず、分析も動かしていません。 配信のために GitHub と Cloudflare がリクエストを処理し、フォントは Google Fonts から読み込まれるため、訪問時に IP アドレスが同社に渡ります。
