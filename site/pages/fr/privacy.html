Confidentialité

Local par défaut, avec des exceptions documentées

Flowlight ne demande aucun compte et n’embarque aucune analytique produit. Les enregistrements de trafic sont stockés localement. Cette page documente ce que l’app enregistre, les fonctionnalités facultatives qui contactent des services externes, et comment vérifier ces affirmations dans le code source.

En bref

  • Flowlight enregistre des métadonnées réseau (quelle app, quel hôte, quel port, combien d’octets, quand) dans une base de données sur votre Mac.
  • Il n’enregistre jamais le contenu des paquets et ne déchiffre jamais le trafic, sauf si vous activez l’inspection HTTPS facultative pour les apps que vous faites passer par lui.
  • Flowlight n’envoie pas sa base de données de trafic et n’embarque ni télémétrie, ni rapport de plantage, ni analytique produit.
  • Les requêtes externes de l’app elle-même et les chemins d’exportation que vous configurez sont documentés ci-dessous.

Ce qu’il enregistre

Pour chaque seconde : l’app (identifiant de bundle, nom, chemin de l’exécutable, identifiant de processus), l’adresse IP distante, le nom d’hôte, le port, le transport et le protocole, et les octets envoyés et reçus. Il stocke aussi les alertes qu’il déclenche et les références par app utilisées par les règles d’anomalie. Tout cela vit dans ~/Library/Application Support/Flowlight.

Capture de paquets

Si vous approuvez la configuration unique des noms d’hôte, Flowlight lit les paquets sur votre interface réseau principale à travers un filtre du noyau qui ne laisse passer que deux choses : les réponses DNS, et le premier message d’une connexion TLS (le ClientHello). Il n’en garde que les noms d’hôte et les adresses auxquelles ils correspondent, en mémoire. Tout le reste est écarté dans le noyau, et aucun paquet n’est écrit sur le disque.

Ce qu’il lit sur votre Mac

Pour attribuer les outils et les serveurs MCP d’un agent, Flowlight lit auprès de macOS le parent et la ligne de commande de chaque processus, ainsi que les fichiers de configuration MCP des agents qu’il prend en charge (par exemple ~/.claude.json, ~/.cursor/mcp.json et ~/.codex/config.toml). Il ne garde en mémoire que le nom, la commande de lancement et l’URL de chaque serveur, et ne stocke avec votre trafic que les étiquettes qui en résultent (« via curl », « github MCP »). Rien de ces fichiers ni de ces lignes de commande n’est envoyé où que ce soit.

Inspection HTTPS

Désactivée par défaut. Si vous l’activez, Flowlight crée une autorité de certification sur votre Mac (sa clé ne quitte jamais ~/Library/Application Support/Flowlight/Inspection) et fait tourner un proxy qui n’accepte de connexions que depuis ce Mac. Pour les apps que vous faites passer par lui, il enregistre les requêtes et les réponses, corps compris jusqu’à 2 MB, dans la base de données locale pendant 3 jours. Les en-têtes d’identification (Authorization, cookies, clés d’API) sont remplacés par leur longueur avant tout enregistrement. Flowlight exclut du déchiffrement sa liste intégrée de services Apple et de gestionnaires de mots de passe. Les données d’inspection enregistrées ne sont pas envoyées par Flowlight. Désactiver l’inspection arrête le proxy ; Supprimer le certificat & les données enregistrées supprime le certificat, son réglage d’approbation et chaque requête enregistrée.

Autorisations

  • Mot de passe administrateur, une fois, pour l’accès à la capture de paquets. Retirable depuis l’écran Capture.
  • Notifications, pour les avertissements. Facultatif.
  • Élément d’ouverture, seulement si vous activez Lancer à l’ouverture de session.

Conservation

Les données par seconde 6 heures (réglable), les données à la minute 14 jours, les données horaires 400 jours, les totaux quotidiens indéfiniment, les alertes 90 jours. Capture › Effacer toutes les données supprime tout, et retirer ~/Library/Application Support/Flowlight fait de même.

Ce site

Ce site est une page statique hébergée sur GitHub Pages et servie via Cloudflare. Il ne dépose aucun cookie et n’exécute aucune analytique. GitHub et Cloudflare traitent les requêtes pour le servir, et les polices sont chargées depuis Google Fonts, qui reçoit votre adresse IP lors de votre visite.
