Privacidad

Local por defecto, con excepciones documentadas

Flowlight no necesita cuenta y no incluye analítica de producto. Los registros de tráfico se guardan en local. Esta página documenta qué registra la app, qué funciones opcionales contactan con servicios externos y cómo verificar todo esto en el código fuente.

En resumen

  • Flowlight registra metadatos de red (qué app, qué host, qué puerto, cuántos bytes y cuándo) en una base de datos de tu Mac.
  • Nunca registra el contenido de los paquetes ni descifra el tráfico, salvo que actives la inspección HTTPS opcional para las apps que encamines por ella.
  • Flowlight no sube su base de datos de tráfico y no incluye telemetría, informes de errores ni analítica de producto.
  • Las peticiones externas que hace la propia app y las vías de exportación que configura el usuario están documentadas más abajo.

Qué registra

De cada segundo: la app (identificador de paquete, nombre, ruta del ejecutable, identificador de proceso), la dirección IP remota, el nombre de host, el puerto, el transporte y el protocolo, y los bytes enviados y recibidos. También guarda las alertas que genera y las líneas base por app que usan las reglas de anomalías. Todo ello vive en ~/Library/Application Support/Flowlight.

Captura de paquetes

Si apruebas la configuración inicial de los nombres de host, Flowlight lee los paquetes de tu interfaz de red principal a través de un filtro en el núcleo que deja pasar solo dos cosas: las respuestas DNS y el primer mensaje de una conexión TLS (el ClientHello). De ahí conserva únicamente los nombres de host y las direcciones a las que corresponden, en memoria. Todo lo demás se descarta en el núcleo, y no se escribe ningún paquete en el disco.

Lo que lee en tu Mac

Para atribuir las herramientas y los servidores MCP de un agente, Flowlight lee de macOS el proceso padre y la línea de comandos de cada proceso, y los archivos de configuración MCP de los agentes compatibles (por ejemplo ~/.claude.json, ~/.cursor/mcp.json y ~/.codex/config.toml). Conserva solo el nombre, el comando de arranque y la URL de cada servidor, en memoria, y guarda únicamente las etiquetas resultantes («vía curl», «MCP github») junto a tu tráfico. Nada de esos archivos ni de esas líneas de comandos se envía a ninguna parte.

Inspección HTTPS

Desactivada por defecto. Si la activas, Flowlight crea una autoridad de certificación en tu Mac (su clave no sale nunca de ~/Library/Application Support/Flowlight/Inspection) y ejecuta un proxy que acepta conexiones solo de este Mac. En las apps que encamines por él, registra las peticiones y las respuestas, incluidos los cuerpos de hasta 2 MB, en la base de datos local durante 3 días. Las cabeceras con credenciales (Authorization, cookies, claves de API) se sustituyen por su longitud antes de guardar nada. Flowlight excluye del descifrado su lista integrada de servicios de Apple y gestores de contraseñas. Flowlight no sube los datos de inspección registrados. Al desactivar la inspección se detiene el proxy; Eliminar el certificado y los datos registrados borra el certificado, su ajuste de confianza y todas las peticiones registradas.

Permisos

  • Contraseña de administrador, una vez, para el acceso a la captura de paquetes. Se puede retirar desde la pantalla Captura.
  • Notificaciones, para las advertencias. Opcional.
  • Ítem de inicio, solo si activas Abrir al iniciar sesión.

Conservación

Datos por segundo, 6 horas (ajustable); datos por minuto, 14 días; datos horarios, 400 días; totales diarios, indefinidamente; alertas, 90 días. Captura › Borrar todos los datos lo elimina todo, y eliminar ~/Library/Application Support/Flowlight hace lo mismo.

Este sitio web

Este sitio es una página estática alojada en GitHub Pages y servida a través de Cloudflare. No pone cookies y no ejecuta analítica. GitHub y Cloudflare procesan las peticiones para servirlo, y las tipografías se cargan desde Google Fonts, que recibe tu dirección IP cuando lo visitas.
