Flowlight가 있는 이유

이제 도구가 스스로 결정합니다. 그럴 때 내 데이터가 어디로 가는지 볼 수 있어야 합니다.

코딩 에이전트는 파일을 읽고 명령을 실행하고 도구를 호출하며, 그 도구는 어느 것이든 소켓을 열 수 있습니다. 2026년 9월, 어떤 AI 코딩 앱이 사용자의 작업 공간 전체를 Git 기록까지 묶어 백그라운드로 업로드하고 있었다는 사실이 드러났습니다. 이를 잡아낸 연구자도 캐시 폴더가 디스크를 잡아먹는 것을 보고서야 알아챘습니다.

업로드는 암호화되어 있었지만 정작 중요한 사실들은 그렇지 않았습니다. 어떤 앱이, 어떤 호스트로, 몇 메가바이트를, 언제. macOS는 이미 그 전부를 알고 있습니다. Flowlight는 그것을 화면에 올리고 기록으로 남기며, 이상한 것을 표시합니다.

HTTPS 검사 · 선택 사항

도구 호출과 네트워크 요청을 잇습니다

기본값은 끔입니다. 켜면 Flowlight는 Mac 안에서 만든 자체 인증 기관을 가진 로컬 프록시가 됩니다. 검사 대상인 터미널에서 에이전트를 실행하면 에이전트와 그 도구의 지원되는 HTTP 트래픽이 복호화되고, 모델이 요청한 도구 호출과 되돌아간 결과가 함께 보입니다.

도구 호출과 결과

Anthropic, OpenAI, Gemini, MCP. 각 호출의 명령과 출력 또는 오류, 그리고 그 도구가 낸 요청까지.

모델과 토큰

어떤 모델이 답했는지, 호출은 몇 번인지, 그리고 입력·출력·캐시에서 제공된 토큰을 에이전트별로.

명시적으로 통제

검사는 기본적으로 AI 에이전트만 대상으로 합니다. Flowlight는 내장된 Apple 서비스와 암호 관리자 목록을 제외하고, 저장하기 전에 인증 정보 헤더를 가리며, 인증서와 기록된 데이터를 지우는 동작을 하나 제공합니다.

로컬 SQLite 파일 하나. 계정도, 클라우드 동기화도, 텔레메트리도 없습니다.

커널에서 걸러냅니다

캡처는 DNS 응답과 TLS ClientHello만 통과시킵니다. 나머지는 Flowlight가 보기 전에 버려집니다.

조회는 내가 정합니다

주소의 소유자를 알아낼 때는 호스트 이름이 없는 공용 IP만 Team Cymru로 보내며, 클릭 한 번으로 끌 수 있습니다. 하루 한 번 업데이트 확인은 GitHub에 최신 버전만 물어보고, 이것도 끌 수 있습니다.

설치

1분 안에 돌아갑니다

  1. Flowlight.dmg 다운로드

    열어서 Flowlight를 응용 프로그램으로 드래그하세요. 릴리스마다 .pkg 설치 프로그램도 함께 제공됩니다. 릴리스는 Developer ID 인증서로 서명되고 Apple의 공증을 받습니다.

  2. 실행하기

    1초 안에 트래픽이 나타나고, 메뉴 막대에 실시간 ↓↑ 속도가 자리 잡습니다.

  3. 트래픽에 이름 붙이기

    한 번만 하는 설정을 승인하면(암호 입력은 한 번뿐) Flowlight가 호스트 이름을 읽을 수 있습니다.

자주 묻는 질문

질문과 답

Flowlight가 트래픽을 차단합니까?

기본적으로는 지켜보고 알립니다. 에이전트가 허용 목록을 벗어날 때도 알립니다. 그런 연결을 거부할 수도 있지만, 그 기능을 켜 둔 에이전트에 한해서만, 그리고 네트워크 확장 엔진이 설치된 경우에만 가능합니다. 샘플러는 보는 것만 할 수 있습니다. 로컬 트래픽과 DNS, Apple 서비스, Flowlight 자신의 연결은 절대 거부하지 않습니다.

내 HTTPS 트래픽을 읽을 수 있습니까?

기본값으로는 읽지 않습니다. 클라이언트가 연결을 열 때 요청하는 호스트 이름(TLS SNI)과 이름을 주소로 이어 주는 DNS 응답을 읽고, 내용은 암호화된 채로 둡니다. 전체를 보고 싶다면 HTTPS 검사가 따로 있습니다. 직접 켜야 하는 모드로, Flowlight가 자체 인증 기관을 가진 로컬 프록시가 되어 그리로 보낸 앱(기본값은 AI 에이전트만)을 복호화하며, 모델이 에이전트에게 실행하라고 요청한 모든 도구 호출까지 포함합니다. 인증서를 고정하는 앱은 이를 거부할 수 있습니다. Flowlight는 내장된 Apple 서비스와 암호 관리자 목록을 검사에서 제외합니다.

Little Snitch나 LuLu와 무엇이 다릅니까?

그 도구들은 연결을 허용할지 묻는 방화벽입니다. Flowlight는 분석 도구입니다. 어떤 배율로든 볼 수 있는 기록, 이상 탐지 기준선, 그리고 AI 에이전트를 위해 만든 규칙. 둘을 나란히 써도 잘 맞습니다.

왜 암호를 묻습니까?

macOS는 관리자만 네트워크 패킷을 읽게 합니다. 한 번만 하는 설정으로 내 계정에 읽기 권한을 주는데, Wireshark도 같은 방식입니다. 캡처 화면에서 언제든 되돌릴 수 있습니다.

어떤 MCP 서버나 도구가 요청을 냈는지 알 수 있습니까?

프로세스 수준에서는 알 수 있습니다. Flowlight는 각 프로세스를 시작한 에이전트까지 거슬러 올라가므로, 셸 도구의 curl이나 MCP 서버의 연결이 그 에이전트에 귀속되고, MCP 서버의 이름은 Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Codex, Zed, Gemini CLI 설정에서 가져옵니다. 오래 떠 있는 서버 안에서 어떤 개별 도구 호출이 연결을 열었는지는 알 수 없습니다.

허용 목록이 트래픽을 차단합니까?

허용 목록은 기본적으로 위반을 보고합니다. 네트워크 확장이 활성화되어 있으면 에이전트별로 적용을 켜서 목록에 없는 목적지를 거부할 수 있습니다. nettop 샘플러는 위반을 보고할 수는 있지만 연결을 차단하지는 못합니다.

어떤 에이전트를 인식합니까?

Claude Code, Codex, Cursor, Windsurf, GitHub Copilot, Gemini CLI, Aider, Goose, OpenCode, Ollama, LM Studio, ChatGPT, Claude, Zed, Perplexity, ZCode, 그리고 알려진 LLM API를 호출하는 브라우저가 아닌 모든 프로세스입니다. 하나를 더하는 일은 한 줄짜리 풀 리퀘스트입니다.

업데이트는 어떻게 합니까?

Flowlight는 하루에 한 번 GitHub에 최신 릴리스를 확인합니다. 새 릴리스가 있으면 릴리스 노트를 보여주고, 디스크 이미지를 받아 공개된 SHA-256과 맞춰 검증한 뒤 열어 줍니다. 이 확인은 설정에서 끌 수 있습니다.

정말 무료입니까?

네. GPL-3.0을 따르는 자유 소프트웨어입니다. 유료 등급도, 데이터 수집도 없습니다.
