一句话概括

  • Flowlight 把网络元数据（哪个应用、哪台主机、哪个端口、多少字节、什么时候）记录在你 Mac 上的一个数据库里。
  • 它绝不记录数据包内容，也绝不解密流量，除非你为交给它转发的应用打开可选的 HTTPS 检查。
  • Flowlight 不会上传它的流量数据库，也不含遥测、崩溃上报或产品分析。
  • 应用自身发出的外部请求，以及由用户配置的导出路径，都在下面列明。

它记录什么

对每一秒：应用（Bundle ID、名称、可执行文件路径、进程 ID）、远端 IP 地址、主机名、端口、传输层与 应用层协议，以及发送和接收的字节数。它还会保存自己发出的警报，以及异常规则用到的各应用基线。 所有这些都存放在 ~/Library/Application Support/Flowlight 里。

数据包捕获

如果你同意那次一次性的主机名设置，Flowlight 会通过一个内核过滤器读取主网络接口上的数据包，该过滤器 只放行两样东西：DNS 响应，以及 TLS 连接的第一条消息（ClientHello）。它只从其中保留 主机名和它们映射到的地址，并放在内存里。其余一切都在内核中被丢掉，没有任何数据包会写入磁盘。

它在你的 Mac 上读取什么

为了把代理的工具和 MCP 服务器归属清楚，Flowlight 会从 macOS 读取每个进程的父进程和命令行，以及它 支持的那些代理的 MCP 配置文件（例如 ~/.claude.json、~/.cursor/mcp.json 和 ~/.codex/config.toml）。它只在内存中保留每个服务器的名称、启动命令和 URL，随流量一起存下来的只有由此得出的 标签（“经由 curl”“github MCP”）。这些文件和命令行里的内容不会发往任何地方。

HTTPS 检查

默认关闭。如果你打开它，Flowlight 会在你的 Mac 上创建一个证书颁发机构（它的私钥绝不离开 ~/Library/Application Support/Flowlight/Inspection），并运行一个只接受来自本机连接的代理。对于你 交给它转发的应用，它会把请求和响应（含最多 2 MB 的正文）记录在本地数据库里，保留 3 天。凭据标头 （Authorization、cookie、API 密钥）在任何内容被存储之前，都会被替换为它们的长度。Flowlight 会把内置的 Apple 服务和密码管理器名单排除在解密之外。记录下来的检查数据不会被 Flowlight 上传。关掉检查会停止代理；移除证书与记录的 数据会删除证书、它的信任设置以及每一条已记录的请求。

权限

  • 管理员密码，一次，用于数据包捕获访问权限。可在捕获界面里移除。
  • 通知，用于警告。可选。
  • 登录项，仅在你打开“登录时启动”时。

保留期限

每秒数据 6 小时（可调），分钟数据 14 天，小时数据 400 天，每日总量无限期保留，警报 90 天。 捕获 › 清除所有数据会删除一切，删除 ~/Library/Application Support/Flowlight 也是同样的效果。

本网站

本站是托管在 GitHub Pages 上、经由 Cloudflare 提供服务的静态页面。它不设置 cookie，也不运行任何分析。GitHub 和 Cloudflare 会处理请求以便提供服务，而字体从 Google Fonts 加载，你访问时它会收到你的 IP 地址。
