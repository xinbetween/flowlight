应用级网络洞察 · macOS 15+

看清应用的网络活动。
读懂你的 AI 代理。

Flowlight 显示哪些应用在联网、去了哪里、传了多少数据。对 AI 代理，它还会追踪工具、 MCP 服务器和目标——陌生主机、敏感通道和异常上传就此一眼可见。

⛔ 拒绝

规则管多久，你说了算

指定一个应用、一个代理、一个目标或单个 URL 就能阻止它——在发现它的那一行右键即可。 可以永久生效、到某个时间、到 Flowlight 退出，或只在选定的时段内生效；有一个暂停开关，每次拒绝也都留着出口。 最具体的规则胜出，打平时以阻止为准。

⛔ 拒绝

给代理的工具加护栏

阻止一个 MCP 服务器、它的某个工具，或某个资源。被拒绝的工具会从代理发给模型的清单里移除， 模型根本看不到它——没有需要争辩的拒绝，也没有重试循环。它需要 HTTPS 检查；而且它不是沙盒： Flowlight 明说这一点，而不是含糊其辞。

Flowlight 为何存在

你的工具如今会自己做决定。它们这么做的时候，你应该看得见数据去了哪里。

编程代理会读你的文件、执行命令、调用工具，而其中任何一个工具都可能打开一个 socket。2026 年 9 月， 有人发现一款 AI 编程应用把用户的整个工作区连 Git 历史一起打包，在后台上传。 抓到它的那位研究者，只是因为缓存文件夹把磁盘吃光了才注意到。

上传的内容是加密的，但真正要紧的事实并没有：哪个应用、哪台主机、多少兆字节、什么时候。 这些 macOS 本来就知道。Flowlight 把它们放到屏幕上，留下历史，并标出不对劲的地方。

HTTPS 检查 · 可选

把受支持的工具调用与网络请求对上

默认关闭。打开后，Flowlight 会成为一个本地代理，使用在你 Mac 上生成的专属证书颁发机构。 从受检查的终端启动代理，代理及其工具的受支持 HTTP 流量就会被解密，并附上模型请求的工具调用和返回的结果。

工具调用与结果

支持 Anthropic、OpenAI、Gemini 和 MCP。每次调用都带上它的命令、输出或错误，以及这个工具发出的请求。

模型与 token

哪个模型作答、调用了多少次，以及每个代理的输入、输出和由缓存提供的 token 数。

可读的请求体

JSON 按原始顺序呈现为可折叠的树，流式响应逐个事件呈现，还有头部和原始视图。

明确受你控制

检查默认只针对 AI 代理。Flowlight 会把内置的 Apple 服务和密码管理器名单排除在外，在存储前抹去凭据标头，并提供一个操作来移除证书和已记录的数据。

隐私

一个不用你盯着的监控工具

只留在你的 Mac 上

一个本地 SQLite 文件。没有账号，不做云同步，不收遥测。

默认只看元数据

主机名、端口和字节数。解密 HTTPS 是另一个要你自己打开的模式，而且同样只在你的 Mac 上。

在内核里就筛掉

捕获只放行 DNS 应答和 TLS ClientHello。其余一切在 Flowlight 看到之前就被丢掉了。

查询由你掌控

要查出某个地址归谁所有，只会把没有主机名的公网 IP 发给 Team Cymru，一键即可关闭。每日更新检查只向 GitHub 询问最新版本，同样可以关掉。

常见问题

问答

Flowlight 会拦截流量吗？

默认情况下它只观察并提醒，包括代理离开允许列表的时候。它也可以拒绝那些连接， 但仅限你为之开启了这项设置的代理，而且必须装有网络扩展引擎——采样器只能观察。 本地流量、DNS、Apple 服务以及 Flowlight 自己的连接永远不会被拒绝。

它能读我的 HTTPS 流量吗？

默认不能。它读取客户端建立连接时请求的主机名（TLS SNI），以及把域名映射到地址的 DNS 应答， 内容始终保持加密。如果你想看到全貌，HTTPS 检查是一个独立的、需自行开启的模式： Flowlight 会成为带有自己证书颁发机构的本地代理，并解密你交给它转发的应用（默认只有 AI 代理）， 包括模型要求代理执行的每一次工具调用。固定了证书的应用可能拒绝它。 Flowlight 会把内置的 Apple 服务和密码管理器名单排除在检查之外。

它和 Little Snitch 或 LuLu 有什么不同？

那些是防火墙，会请你逐个放行连接。Flowlight 是分析工具：任意粒度的历史、 异常基线，以及为 AI 代理而做的规则。两者并用效果很好。

它为什么要我的密码？

macOS 只允许管理员读取网络数据包。一次性设置会给你的账户读取权限， 和 Wireshark 的做法一样。你随时可以在“捕获”界面里把它移除。

它能分辨是哪个 MCP 服务器或工具发出的请求吗？

能，到进程这一层。Flowlight 会沿着每个进程追回启动它的那个代理，所以 shell 工具的 curl 或某个 MCP 服务器的连接都会归到那个代理名下；MCP 服务器的名字取自 Claude Code、Claude Desktop、Cursor、Windsurf、VS Code、Codex、Zed 和 Gemini CLI 的配置。它无法看出在一个 长期运行的服务器里，究竟是哪一次工具调用开了连接。

允许列表会拦截流量吗？

允许列表默认只报告违规。网络扩展处于活动状态时，你可以为某个代理启用强制执行，未列出的目标就会被拒绝。nettop 采样器可以报告违规，但无法阻止连接。

它能识别哪些代理？

Claude Code、Codex、Cursor、Windsurf、GitHub Copilot、Gemini CLI、Aider、Goose、OpenCode、Ollama、LM Studio、 ChatGPT、Claude、Zed、Perplexity 和 ZCode，再加上任何调用已知 LLM API 的非浏览器进程。 新增一个只需一行的拉取请求。

它怎么更新？

Flowlight 每天向 GitHub 查询一次最新版本。有新版本时，它会显示更新说明，并可以下载 磁盘映像、用公布的 SHA-256 校验，然后打开它。你可以在“设置”里关掉这项检查。

它真的免费吗？

是。它是 GPL-3.0 下的自由软件：没有付费版，不收集数据。
