Flowlight は、どのアプリがどこへつながり、どれだけのデータを動かしたかを示します。AI エージェントについては、ツールや MCP サーバ、接続先までたどるので、見慣れないホストや機密性の高い経路、いつもと違う送信が浮かび上がります。

アプリ単位でネットワークを見る

Flowlight は観測した TCP と UDP の通信をアプリに結び付け、接続先・プロトコル・バイト数をローカルに記録します。 どこまで見えるかは、選んだキャプチャソースと得られるホスト名の情報によって変わります。

アプリ単位

アプリ、コマンドラインツール、バックグラウンドのサービスをプロセス単位で判別します。認識済みエージェントの子プロセスも含みます。

ホスト名を解決

観測した TLS のサーバ名と DNS の応答から学習します。ホスト名がわからない場合は、任意でネットワークの所有者を調べられます。

⚠ 重大

許可リスト違反

「Claude Code は GitHub と npm だけ、ほかはだめ」。ドメイン・IP・範囲を追加するか、プリセットから始めます。 それ以外に出ればアラートになり、許可はワンクリックです。そう指示しておけば、ネットワーク機能拡張が 報告するだけでなく接続そのものを拒否します。

Claude Code › curl が paste.example:443 に接続。Claude Code の許可リストにありません

⛔ 拒否

期間を決められるルール

アプリ、エージェント、接続先、あるいは 1 つの URL を指定してブロックします。見つけた行を右クリックするだけです。 ずっと、指定の時刻まで、Flowlight を終了するまで、または決めた時間帯だけ。一時停止のスイッチが 1 つあり、拒否のたびに 抜け道も示します。いちばん具体的なルールが勝ち、同じ強さなら拒否が勝ちます。

Cursor ⇥ raw.githubusercontent.com · 4 回拒否 · 平日 18:00–09:00

⛔ 拒否

エージェントのツールにガードレール

MCP サーバ全体、その中の 1 つのツール、あるいは 1 つのリソースをブロックできます。拒否したツールは、エージェントが モデルに送る一覧から取り除かれます。モデルにはそもそも提示されないので、拒否をめぐるやり取りも再試行の繰り返しも起きません。 HTTPS インスペクションが必要です。そしてこれはサンドボックスではありません。Flowlight はそこをごまかさず明言します。

Claude Code：Bash なし、write* なし · 本日の宣言から 12 個のツールを除外

ツールと MCP サーバ

エージェントのシェルツールが実行する curl や git、npm、そして起動した MCP サーバの通信は、そのエージェントのトラフィックとして数えます。名前はエージェント自身の MCP 設定から取ります。

Flowlight をつくった理由

あなたの道具は、いまや自分で判断します。ならば、データがどこへ行くのかは見えていいはずです。

コーディングエージェントはファイルを読み、コマンドを実行し、ツールを呼びます。そのどのツールもソケットを開けます。2026 年 9 月には、 ある AI コーディングアプリが、Git の履歴を含むワークスペース全体をまとめ、バックグラウンドで送信していたことが判明しました。 気づいた研究者のきっかけは、キャッシュフォルダがディスクを食いつぶしていたことでした。

送信内容は暗号化されていましたが、肝心な事実は暗号化されていません。どのアプリが、どのホストへ、何メガバイト、いつ。 macOS はそのすべてをすでに知っています。Flowlight はそれを画面に出し、履歴として残し、おかしなものに印を付けます。

HTTPS インスペクション · 任意

対応するツール呼び出しとネットワークリクエストを結び付ける

初期状態ではオフです。オンにすると Flowlight は、Mac 上で作った独自の証明書認証局を持つローカルプロキシになります。 インスペクト対象のターミナルからエージェントを起動すれば、エージェントとそのツールの対応 HTTP 通信が復号され、モデルが要求した ツール呼び出しと、返っていった結果まで見えます。

ツール呼び出しと結果

Anthropic、OpenAI、Gemini、MCP に対応。呼び出しごとに、コマンド、出力またはエラー、そのツールが出したリクエストを記録します。

モデルとトークン

どのモデルが答えたか、呼び出し回数、入力・出力・キャッシュから返されたトークン数を、エージェントごとに表示します。

読めるボディ

JSON は元の順序のまま折りたためるツリーで、ストリームはイベントを 1 件ずつ。ヘッダと生データの表示もあります。

制御は明示的に

インスペクトの対象は、初期状態では AI エージェントです。Flowlight は内蔵の一覧にある Apple のサービスとパスワード管理アプリを除外し、認証情報のヘッダは保存前に伏せ、証明書と記録したデータをまとめて削除する操作を用意しています。

次に来るもの

これから

Flowlight は今日すでに、監視し、説明し、拒否します。残りはこの順番で作っています。

まず Linux、次に Windows

分析の中核は移植できる Swift ですが、キャプチャはそうではありません。まずローカルの Web UI を備えた Linux 用デーモンを、macOS の API ではなく eBPF の上に作ります。

FAQ

よくある質問

Flowlight はトラフィックをブロックしますか？

初期状態では監視して知らせるだけで、エージェントが許可リストを外れた場合も同じです。その接続を拒否することもできますが、 拒否を有効にしたエージェントに限られ、さらにネットワーク機能拡張エンジンが入っている必要があります。サンプラーは監視しかできません。 ローカルのトラフィック、DNS、Apple のサービス、そして Flowlight 自身の接続は、けっして拒否されません。

HTTPS の通信内容を読めますか？

初期状態では読みません。読むのは、クライアントが接続を開くときに求めるホスト名（TLS SNI）と、名前をアドレスに対応づける DNS の応答だけで、中身は暗号化されたままです。すべてを見たい場合は、HTTPS インスペクションという別のオプトインの モードがあります。Flowlight が独自の証明書認証局を持つローカルプロキシになり、そこを通すよう指定したアプリ（初期状態では AI エージェント だけ）を復号します。モデルがエージェントに実行させるツール呼び出しも、すべて含まれます。証明書をピン留めするアプリは拒否することが あります。内蔵の一覧にある Apple のサービスとパスワード管理アプリは、インスペクトの対象から除外されます。

Little Snitch や LuLu との違いは何ですか？

あちらは接続を許可するかどうかを尋ねるファイアウォールです。Flowlight は分析ツールで、どのズームでも見られる履歴、 異常検出の基準値、AI エージェント向けに作られたルールを備えます。併用しても問題なく動きます。

なぜパスワードを求めるのですか？

macOS では管理者だけがネットワークパケットを読めます。初回だけのセットアップで、Wireshark と同じやり方で アカウントに読み取り権限を与えます。キャプチャ画面からいつでも取り消せます。

どの MCP サーバやツールがリクエストを出したかわかりますか？

プロセス単位でわかります。Flowlight は各プロセスを起動元のエージェントまでたどるので、シェルツールの curl や MCP サーバの接続はそのエージェントに結び付きます。MCP サーバの名前は Claude Code、Claude Desktop、Cursor、Windsurf、 VS Code、Codex、Zed、Gemini CLI の設定から取ります。ただし、動き続けているサーバの中で、どの個別のツール呼び出しが 接続を開いたのかまではわかりません。

許可リストはトラフィックをブロックしますか？

許可リストは、初期状態では違反を報告します。ネットワーク機能拡張が有効な場合は、エージェントごとに強制を有効にでき、一覧にない接続先は拒否されます。nettop サンプラーは違反を報告できますが、接続をブロックすることはできません。

どのエージェントを認識しますか？

Claude Code、Codex、Cursor、Windsurf、GitHub Copilot、Gemini CLI、Aider、Goose、OpenCode、Ollama、LM Studio、 ChatGPT、Claude、Zed、Perplexity、ZCode、そして既知の LLM API を呼ぶブラウザ以外のプロセスすべてです。追加は 1 行のプルリクエストで済みます。

アップデートはどのように行われますか？

Flowlight は 1 日 1 回 GitHub に最新リリースを問い合わせます。新しいものがあればリリースノートを表示し、ディスクイメージの ダウンロード、公開された SHA-256 との照合、そして開くところまで行えます。この確認は設定でオフにできます。

本当に無料ですか？

はい。GPL-3.0 のもとで公開されている自由ソフトウェアです。有料プランもデータ収集もありません。
