脅威モデル

監視であって、防止ではない

Flowlight は、Mac 上のソフトウェアが何をどこへ送っているかを教えます。すでにマシンを手中にしている攻撃者に対する 防御ではありません。その違いは、脚注ではなく独立した 1 ページで述べるだけの重さがあります。

何のためにあるのか

Flowlight は、Mac が答えてくれない問いに答えます。どのアプリがこれを送り、どこへ行ったのか。作られた相手は、 隠れもせずに行儀の悪いソフトウェアです。誰も頼んでいない先に接続する AI エージェント、送るべき以上をアップロードするツール、 名前のないアドレスと話しているプロセス。そうした振る舞いはトラフィックに現れます。Flowlight の仕事は、それを読めるようにすること、 そして読めないときには正直にそう言うことです。

アンチウイルスではなく、EDR エージェントでもなく、あなたと攻撃者のあいだに立つという意味でのファイアウォールでもありません。 両者が重なるところ、つまり Flowlight が接続を拒否できるところでも、その拒否はすでに信頼しているソフトウェアを制御するための 便利さであって、信頼していないソフトウェアに対する防壁ではありません。

何を防ぐのか

  • 気づかれないまま出ていくデータ。アプリやエージェントが、あなたなら承認しなかった先へ送ること。エージェント自身が 実行したツール経由の場合も含みます。Flowlight はその接続を、接続を行ったプロセスと、そのプロセスを起動したエージェントに 結び付けます。
  • 静かな振る舞いの変化。急に新しい接続先と通信しはじめたアプリ、ベースラインよりはるかに多く動かすアプリ、 あなたが離れているあいだに働くアプリ。どのアラートも、それを引き起こした数値を示します。だからあなたはそれに異を唱えられます。
  • 許した範囲を超えるエージェント。エージェントごとの許可リストと、その外への接続を拒否するルール。拒否は記録され、 ワンクリックで許可できます。
  • 改ざんされたアップデート。どのリリースもチェックサムを公開します。アップデート機能は、検証できないダウンロードを 拒否し、アップデートを求めている実行中のコピーと同じチームが署名していないアプリのインストールを拒否します。

root 権限を持つソフトウェアは、これを止められる

Flowlight はあなたの権限で動き、macOS がその代わりに起動するシステム機能拡張を使います。root で動くものは、そしてあなたが インストーラを承認したものは、その機能拡張をアンロードし、アプリを止め、データベースを削除できます。設計上それを防ぐものは何もなく、 macOS 上のどの監視ツールも、あなた自身が自分で止められるツールでありつづけたまま、それを防ぐことはできません。

正直な主張はもっと狭く、それでも役に立ちます。行儀が悪いだけで、監視から積極的に逃れようとはしていないソフトウェアは見えます。 積極的に逃れているソフトウェアは見えないかもしれません。それでも少なくとも空白は残ります。止まった機能拡張、データのない期間です。 それを示すためにカバー範囲の画面があります。

キャプチャが取りこぼすもの

  • キャプチャを始める前のトラフィック。あとから埋めることはできません。フィルタより先に開いた接続は、 そもそもフィルタに渡されていません。
  • コンテンツフィルタの対象外となるシステムサービス。macOS はコンテンツフィルタに何もかもを見せるわけではありません。 macOS 自身のトラフィックの一部は、こちらには決して届きません。
  • その枠を別のコンテンツフィルタが握っている場合。macOS が動かすのは同時に 1 つだけです。VPN やセキュリティ エージェントがそれを握っていると、Flowlight のフィルタはインストールされ、接続もしますが、何かをフィルタするよう求められることは ありません。キャプチャは、空の画面を見せるのではなく、そう伝えます。
  • 短い接続。サンプラーの場合です。機能拡張がなければ、Flowlight は 1 秒ごとにカウンタを読みます。2 回の読み取りの あいだに開いて閉じる接続は、決して記録されません。
  • TCP でも UDP でもない経路。Bluetooth と USB はデバイスとしては見えますが、バイト数としては見えません。 エージェントのローカルの MCP サーバがパイプで話すものは、そもそもネットワークトラフィックではなく、どこにも現れません。

インスペクションが取りこぼすもの

HTTPS インスペクションが読めるのは、Flowlight のローカルプロキシを経由したものだけで、それを決めるのはプログラムが起動する 瞬間です。プロキシ設定を無視するアプリ、インスペクションをオンにする前に起動したアプリ、証明書をピン留めするアプリは、手を加えられずに 通り過ぎます。これは意図してそうしています。ピン留めされた接続を壊せば、そのアプリが壊れるからです。QUIC もプロキシには渡されません。

つまり、インスペクトの画面が空なら、それは「ここには何も通されなかった」という意味で、「何も起きなかった」という意味では ありません。どちらなのかは、カバー範囲がアプリごとに答えます。

ブロックとは何で、何でないか

接続を拒否するルールを実行するのはネットワーク機能拡張で、その経路の中で、接続が行われる前に実行します。URL を指定する ルールを実行するのはインスペクション用のプロキシで、アプリが読める状態コードでリクエストに応えます。報告するのではなく実際に 手を出す Flowlight の部分は、この 2 つだけです。nettop サンプラーは何ひとつ拒否できないので、サンプラーで動いている Mac では どのルールも強制されません。Flowlight は何もしないスイッチを見せるのではなく、そのことをはっきり言います。

それでも防止ではありません。シェルを使えるエージェントは、拒否されたツールがしたはずのことを手作業で行えます。ワンクリックで 取り消せる拒否は、エージェントの次の試みが通り抜けうる拒否でもあります。ローカルのトラフィック、DNS、Apple 純正のサービス、 Flowlight 自身の接続は決して拒否されません。ブロックされたエージェントより、ブロックされた Mac のほうが悪い結果だからです。 そして強制は、Flowlight が動作を止めた数秒後に失効します。誰にも見えない拒否は、拒否がないより悪いからです。

インスペクションと拒否は両立しません。Flowlight 自身のプロキシを通ったトラフィックは、Flowlight の トラフィックとして Mac を出ていき、Flowlight が自分自身を拒否することはありません。つまり、リクエストを読んでいるアプリは、 ルールではもう接続を止められないアプリです。もっと見るためにインスペクションをオンにすることは、強制を手放すことでもあり、 画面にはこれまでそう書かれていませんでした。

Flowlight 自身が保持するもの

トラフィックのメタデータを、ローカルの SQLite データベースに、公開された保持期間のあいだ保持します。HTTPS インスペクションを オンにしていれば、リクエストとレスポンスの本文も 3 日間保持します。これは Flowlight が保持するもののなかで最も機微なものです。 認証情報のヘッダは名前と語によって隠されますが、それはヒューリスティックであって保証ではありません。何も認識できない名前のもとに 秘密を載せたヘッダは、記録されることがあります。

トラフィックのデータベースがアップロードされることはありません。それでも、頼まなくても Mac から出ていくものが 3 つあり、 どれもプライバシーのページに挙げてあります。起動時と 1 日 1 回、最新のリリースを GitHub に 尋ねるアップデートの確認。ホスト名のない公開アドレスについて Team Cymru に尋ねるネットワーク所有者の照会。そして、 Flowlight が機能拡張ではなくカウンタを読んでいるあいだ、名前が見つからなかったアドレスの逆引き DNS 照会です。 はじめの 2 つにはオフのスイッチがあります。3 つめにはありません。サンプラーでは、接続に名前が付く道のほとんどがそれだからです。 照会はこの Mac がすでに使っているリゾルバへ行き、機能拡張が引き継いでトラフィック自身から名前を付けるようになれば止まります。 ホスト型モデルでの質問は、そのどれよりもはるかに多くを送りますが、設定するまではオフのままである唯一のものです。

アップデート

リリースは Developer ID で署名され、公証されています。アップデート機能は公開されたチェックサムを要求し、それがないダウンロードを 拒否します。そのうえで、ダウンロードしたアプリが実行中のコピーと同じチームの署名であることを確かめてから、インストールします。 別の誰かが署名したアップデートは、ほかの点で有効であっても拒否されます。

脆弱性を報告する

GitHub のプライベート脆弱性報告をお使いください。GitHub を 使いたくない場合は security@xinbetween.com にメールしてください。対象範囲と 期待してよいことは SECURITY.md に書いてあります。 クラッシュ、数値の誤り、誤解を招く画面といった通常の不具合は、かわりに issue へどうぞ。
