What's new

Downloads, checksums and full notes for each version are on GitHub Releases.

0.2.0

September 23, 2026Latest
  • Opens at the size of your screen. The first launch fills the display instead of a small window, so the timeline, the table and an agent's detail are all readable without resizing first.
  • The agent tabs are always there. Tool calls, Tools and MCP servers used to disappear when they had nothing to show, which also hid the button that finds an agent's configuration. Each one now explains what it needs.
  • Turning on inspection says what it will ask for. Flowlight tells you about both system prompts before the first one appears, skips either if nothing would change, and undoes the certificate if you cancel the second.
  • Fixed: a build that can't use the Network Extension sat on an empty screen. It now falls back to the sampler and says why.
  • New versions arrive as a notification from a daily check, instead of a window taking over what you were doing. The check asks GitHub for the latest version and nothing else, and it can be turned off.

0.1.7

September 23, 2026
  • Setting up HTTPS inspection is one switch. Turning it on creates the certificate, trusts it and routes apps through Flowlight; turning it off undoes all of it. Scope, the never-decrypt list and removal moved under Advanced.
  • Fixed: turning inspection on could fail with "the authorization was denied since no user interaction was possible". Trust now goes through the system's own dialog.
  • Fixed: in a short window, AI Agents hid its description and time picker behind the title bar. The table and the agent's detail now get the space instead.
  • Fixed: processes that exit before Flowlight can read their path showed up as pid 74397, and as agents of their own. They're named from the sampler's own output now.

0.1.6

September 23, 2026
  • Signed and notarized. Releases now carry a Developer ID signature and Apple's notarization, so macOS opens Flowlight without the "unverified developer" wall. Check it with spctl -a -vvv /Applications/Flowlight.app.
  • The Network Extension works. Install the content filter from Capture for per-flow attribution by code signature, flows shorter than a second, and hostnames without the packet-capture setup. It costs less energy than the sampler, which starts a process every second.
  • What each agent is set up to do. With your say-so, Flowlight lists an agent's skills, subagents, slash commands, hooks, permission rules and MCP servers, read from configuration on this Mac. It looks only at the agent folders in your home folder plus project folders you add, and remembers what it found.
  • Tools, models and tokens from inspected calls: every tool an agent offers the model and which were used, the model that answered, tokens in, out and cached, and MCP servers labelled local, remote or via provider.
  • JSON tree viewer for request and response bodies, in their original key order, with a Raw view and Copy.
  • Much lighter when idle. With no window open Flowlight no longer builds chart data for nobody: 4.3 → 0.9 CPU-seconds per minute. A hung nettop can no longer outlive the app and spin in the background.
  • Help menu and a Q&A covering privacy prompts, battery, blocking and uninstalling.

0.1.5

September 22, 2026
  • Tool results and MCP servers. With HTTPS inspection on, each tool call shows what came back (output or error), and each agent's detail gets Tool calls and MCP servers tabs: server name and version, the tools it offers, calls and failures.
  • JSON tree viewer for request and response bodies, in their original key order, with a Raw view and Copy.
  • Fixed: with the system proxy on, Flowlight's own connections looped back through its proxy, recording each request many times and slowing traffic.

0.1.4

September 22, 2026
  • HTTPS inspection (optional, off by default). A local proxy with a certificate authority created on your Mac decrypts the apps you route through it: AI agents and their tools by default. See every request and response in the new Inspect view. Credential headers are never stored, Apple services and password managers are never decrypted, and apps that pin certificates pass through untouched.
  • Tool calls from the model's own responses. Flowlight reads the tool calls a model asks an agent to run (Anthropic, OpenAI, Gemini, MCP tools/call) and links each tool's request back to the call that caused it. AI Agents lists each agent's tools with counts and the latest command.
  • Inspected Terminal. One click opens a shell whose agents (Claude Code, Codex, Gemini CLI, Aider) and tools go through Flowlight, without trusting anything system-wide.

0.1.3

September 22, 2026
  • Quit & Install. Updates download and verify first, then ask before Flowlight quits: Quit & Install replaces the app and reopens it, Install Later keeps you working. You no longer have to quit and drag the new version in yourself.
  • Network owners on by default. Traffic with no hostname is labelled with who operates the address. Only public IPs are looked up, and Capture › Identify network owners turns it off.
  • AI Agents layout. The agent table fits its rows, so the detail pane has room for tools, MCP servers and the allowlist.

0.1.2

September 21, 2026
  • Per-agent allowlists. "Claude Code may talk to GitHub and npm, nothing else": domains, IPs, CIDR ranges and presets, with a critical alert and one-click Allow for anything else.

September 21, 2026
  • ZCode is recognized as an AI agent. After the September 2026 incident, where ZCode uploaded workspace snapshots (mostly .git history) to Alibaba Cloud storage in the background, a transfer like that raises a critical Possible exfiltration alert, with or without a hostname.
