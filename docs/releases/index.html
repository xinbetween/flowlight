What's new

Downloads, checksums and full notes for each version are on GitHub Releases.

0.1.3

September 22, 2026Latest
  • Quit & Install. Updates download and verify first, then ask before Flowlight quits: Quit & Install replaces the app and reopens it, Install Later keeps you working. You no longer have to quit and drag the new version in yourself.
  • Network owners on by default. Traffic with no hostname is labelled with who operates the address. Only public IPs are looked up, and Capture › Identify network owners turns it off.
  • AI Agents layout. The agent table fits its rows, so the detail pane has room for tools, MCP servers and the allowlist.

0.1.2

September 21, 2026
  • Per-agent allowlists. "Claude Code may talk to GitHub and npm, nothing else": domains, IPs, CIDR ranges and presets, with a critical alert and one-click Allow for anything else.
  • Tools & MCP server attribution. Processes an agent starts (shell tools, MCP servers) count as the agent's traffic, with MCP servers named from Claude Code, Cursor, Codex, VS Code and other configs.
  • Update checks. Flowlight looks for new releases daily and offers a download verified against its published SHA-256.
  • About window with copyright, license and links.
  • Relicensed from MIT to the GNU General Public License v3.0.

0.1.1

September 21, 2026
  • ZCode is recognized as an AI agent. After the September 2026 incident, where ZCode uploaded workspace snapshots (mostly .git history) to Alibaba Cloud storage in the background, a transfer like that raises a critical Possible exfiltration alert, with or without a hostname.
  • More LLM providers: Zhipu AI / Z.ai, Moonshot (Kimi), Alibaba Qwen (DashScope API hosts only) and MiniMax. 16 known agents and 25 providers in all.

0.1.0

September 21, 2026First preview
  • Every TCP and UDP flow attributed to its app, with hostnames from TLS SNI and DNS.
  • AI Agents view with sensitive-channel, exfiltration, unnamed-host and while-away rules.
  • 108 protocols in 13 families, reports from second to year, three breakdown groupings, charts and CSV export.
  • Anomaly alerts, a menu bar readout, a disk image and an installer package.
