0.7.1

September 25, 2026Latest
  • Demo mode has its history back. Since 0.4.0 the statement that writes seeded and imported rollups still named an index that release had replaced, so it could not run at all and every seeded row was lost in silence. Demo mode showed live traffic and nothing else.

  • Search and sharing metadata — structured data describing the application, a designed link preview instead of a raw screenshot, and a sitemap that says when each page last changed.

0.6.8

September 25, 2026
  • Rules that name a host now fire. A connection was judged on its first bytes, which is before TLS hands over the name it is going to — a large ClientHello carries it in the second segment, and a DNS answer can land just after. The rule saw no destination, and a connection is judged once.
  • The later segments are kept and read together, instead of being dropped on the floor.
  • The wait is bounded, so a connection straight to an address is still decided promptly, and a name that arrives late is still acted on. How rules work →

0.2.6

September 24, 2026
  • Flowlight says when macOS won't let its filter run. macOS allows one content filter at a time, and on a managed Mac a VPN or security agent usually holds it. Flowlight's filter would install, activate and connect while never being handed a single connection — looking healthy and recording nothing. Capture now lists the other filters by name and offers the sampler, which needs no filter.
  • Fixed: switching to the extension showed an empty Live panel, because it replayed up to an hour of buffered traffic oldest-first before anything current could get through.
  • "Connected" no longer implies "working" — the status distinguishes a live connection from one that is actually being given traffic.
  • A diagnostic script for when capture misbehaves, reporting state and counts and nothing about your traffic.

0.2.5

September 24, 2026
  • Fixed: the filter stopped working after every app update. macOS keeps running whichever build of the extension was last activated, so after an update it was the previous one — and a mismatched pair can't talk to each other. 0.1.7

September 23, 2026

0.1.6

September 23, 2026
  • Signed and notarized. Releases now carry a Developer ID signature and Apple's notarization, so macOS opens Flowlight without the "unverified developer" wall. Check it with spctl -a -vvv /Applications/Flowlight.app.
  • The Network Extension works. Install the content filter from Capture for per-flow attribution by code signature, flows shorter than a second, and hostnames without the packet-capture setup. It costs less energy than the sampler, which starts a process every second.
  • What each agent is set up to do. With your say-so, Flowlight lists an agent's skills, subagents, slash commands, hooks, permission rules and MCP servers, read from configuration on this Mac. It looks only at the agent folders in your home folder plus project folders you add, and remembers what it found.
  • Tools, models and tokens from inspected calls: every tool an agent offers the model and which were used, the model that answered, tokens in, out and cached, and MCP servers labelled local, remote or via provider.
  • JSON tree viewer for request and response bodies, in their original key order, with a Raw view and Copy.
  • Much lighter when idle. With no window open Flowlight no longer builds chart data for nobody: 4.3 → 0.9 CPU-seconds per minute. A hung nettop can no longer outlive the app and spin in the background.
  • Help menu and a Q&A covering privacy prompts, battery, blocking and uninstalling.

0.1.4

September 22, 2026
  • HTTPS inspection (optional, off by default). A local proxy with a certificate authority created on your Mac decrypts the apps you route through it: AI agents and their tools by default. See every request and response in the new Inspect view. Credential headers are never stored, Apple services and password managers are never decrypted, and apps that pin certificates pass through untouched.
  • Tool calls from the model's own responses. Flowlight reads the tool calls a model asks an agent to run (Anthropic, OpenAI, Gemini, MCP tools/call) and links each tool's request back to the call that caused it. AI Agents lists each agent's tools with counts and the latest command.
  • Inspected Terminal. One click opens a shell whose agents (Claude Code, Codex, Gemini CLI, Aider) and tools go through Flowlight, without trusting anything system-wide.
