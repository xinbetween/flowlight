Privacy

Your traffic stays on your Mac

Flowlight has no account, no server and no analytics. This page lists everything it records and every request it makes, so you can check the claims against the source.

In short

  • Flowlight records network metadata (which app, which host, which port, how many bytes, when) in a database on your Mac.
  • It never records packet contents and never decrypts traffic, unless you turn on the optional HTTPS inspection for apps you route through it.
  • Nothing you record is ever sent anywhere. There is no telemetry, crash reporting or analytics.
  • The app makes a few network requests of its own, listed below, and you can turn off each optional one.

What it records

For each second: the app (bundle ID, name, executable path, process ID), the remote IP address, hostname, port, transport and protocol, and bytes sent and received. It also stores the alerts it raises and per-app baselines used by the anomaly rules. All of it lives in ~/Library/Application Support/Flowlight.

Packet capture

If you approve the one-time hostname setup, Flowlight reads packets on your primary network interface through a kernel filter that passes only two things: DNS responses, and the first message of a TLS connection (the ClientHello). From those it keeps only hostnames and the addresses they map to, in memory. Everything else is dropped in the kernel, and no packet is written to disk.

What it reads on your Mac

To attribute an agent's tools and MCP servers, Flowlight reads each process's parent and command line from macOS, and the MCP configuration files of the agents it supports (for example ~/.claude.json, ~/.cursor/mcp.json and ~/.codex/config.toml). It keeps only each server's name, launch command and URL, in memory, and stores only the resulting labels ("via curl", "github MCP") with your traffic. Nothing from these files or command lines is sent anywhere.

HTTPS inspection

Off by default. If you turn it on, Flowlight creates a certificate authority on your Mac (its key never leaves ~/Library/Application Support/Flowlight/Inspection) and runs a proxy that accepts connections only from this Mac. For apps you route through it, it records requests and responses, including bodies up to 2 MB, in the local database for 3 days. Credential headers (Authorization, cookies, API keys) are replaced with their length before anything is stored. Apple services and password managers are never decrypted. Nothing recorded is sent anywhere. Turning inspection off stops the proxy; Remove Certificate & Recorded Data deletes the certificate, its trust setting and every recorded request.

Permissions

  • Administrator password, once, for packet-capture access. Removable from the Capture screen.
  • Notifications, for warnings. Optional.
  • Login item, only if you turn on Launch at login.

Retention

Per-second data 6 hours (adjustable), minute data 14 days, hourly data 400 days, daily totals indefinitely, alerts 90 days. Capture › Clear all data deletes everything, and removing ~/Library/Application Support/Flowlight does the same.

This website

This site is a static page hosted on GitHub Pages and served through Cloudflare. It sets no cookies and runs no analytics. GitHub and Cloudflare process requests to serve it, and the fonts load from Google Fonts, which receives your IP address when you visit.

Contact

Questions or a privacy concern? Open an issue. For anything sensitive, use GitHub's private vulnerability reporting on the repository.
