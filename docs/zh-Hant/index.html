⛔ 拒絕

規則，要生效多久由你說

指名一個 App、一個代理、一個目標或單一 URL，然後把它封鎖 — 在你發現它的那一列上按右鍵就行。 可以永久、到某個時間為止、直到 Flowlight 結束，或只在指定的時段內；另有一個暫停開關，而且每次拒絕都留著 一條退路。最明確的規則優先，兩者相當時以封鎖為準。

⛔ 拒絕

為代理的工具設下防護機制

封鎖一個 MCP 伺服器、它的某個工具，或某一項資源。被拒絕的工具會從代理送給模型的 列表中移除，模型根本不會收到它 — 沒有拒絕訊息可以爭辯，也不會陷入重試循環。這需要開啟 HTTPS 檢查；而且這不是沙箱：Flowlight 直說這一點，不會讓你以為它是。

Flowlight 為何存在

你的工具現在會自己做決定。它們這麼做的時候，你應該看得見你的資料去了哪裡。

寫程式的代理會讀你的檔案、執行指令、呼叫工具，而其中任何一個工具都可以開啟連線。2026 年 9 月， 有人發現一款 AI 程式開發 App 把使用者的整個工作區（連 Git 歷史也一起）打包，然後在背景上傳出去。 抓到它的研究人員之所以注意到，只因為一個快取檔案夾吃掉了磁碟空間。

那些上傳是加密的，但真正重要的事實並沒有被藏住：哪個 App、哪台主機、幾 MB、什麼時候。 macOS 早就知道這一切。Flowlight 把它放到畫面上、保留歷史記錄，並標記出看起來不對的地方。

HTTPS 檢查 · 選用

把支援的工具呼叫和網路請求對起來

預設為關閉。開啟後，Flowlight 會成為本機代理伺服器，使用在你 Mac 上建立的憑證授權 單位。從受檢查的「終端機」啟動代理，它和它的工具所產生的支援 HTTP 流量就會被解密，連同模型要求的 工具呼叫和回傳的結果。

工具呼叫與結果

Anthropic、OpenAI、Gemini 和 MCP。每一次呼叫都附上它的指令、它的輸出或錯誤，以及它的工具發出的請求。

模型與 token

哪個模型回答的、呼叫了幾次，以及輸入、輸出和由快取提供的 token 數，都依代理分開列出。

讀得懂的內文

JSON 以可折疊的樹狀結構按原始順序呈現，串流一次一個事件，另有標頭和原始檢視。

明確可控

檢查功能預設只針對 AI 代理。Flowlight 會排除內建清單中的 Apple 服務和密碼管理程式，在儲存前遮蔽憑證類標頭，並提供一個動作移除憑證與記錄下來的資料。

常見問答

問題

Flowlight 會封鎖流量嗎？

預設情況下，它只監看並發出警示，包括代理離開允許清單的時候。它也可以直接拒絕這些連線， 但僅限你為該代理開啟了這項功能，而且必須安裝網路延伸功能引擎 — 取樣器只能 監看。本機流量、DNS、Apple 服務和 Flowlight 自己的連線一律不會被拒絕。

它能讀我的 HTTPS 流量嗎？

預設不會。它讀取用戶端建立連線時要求的主機名稱（TLS SNI），以及把名稱對應到位址的 DNS 回應，內容則維持加密。如果你想看到完整的樣貌，HTTPS 檢查是另一個 需要自行開啟的模式：Flowlight 會成為本機代理伺服器，使用自己的憑證授權單位，並解密你轉送 經過它的 App（預設只有 AI 代理），包含模型要求代理執行的每一次工具呼叫。使用憑證綁定的 App 可能會拒絕它。Flowlight 會把內建清單中的 Apple 服務和密碼管理程式排除在檢查之外。

這和 Little Snitch 或 LuLu 有什麼不同？

那些是防火牆，會請你決定要不要允許連線。Flowlight 是分析工具：任意縮放層級的歷史記錄、 異常基線，以及為 AI 代理而寫的規則。兩者並用也很合得來。

為什麼它要我的密碼？

macOS 只允許管理者讀取網路封包。一次性的設定會給你的帳號讀取權限，做法和 Wireshark 一樣。你隨時可以在「擷取」畫面中移除它。

它分得出是哪個 MCP 伺服器或工具發出的請求嗎？

可以，到程序這一層。Flowlight 會把每個程序追回啟動它的代理，所以 shell 工具跑的 curl 或 MCP 伺服器的連線，都會歸到那個代理；MCP 伺服器的名稱則取自 Claude Code、Claude Desktop、Cursor、Windsurf、VS Code、Codex、Zed 和 Gemini CLI 的設定。它看不出長時間執行的 伺服器裡，是哪一次工具呼叫開啟了連線。

允許清單會封鎖流量嗎？

允許清單預設只回報違規。網路延伸功能運作時，你可以為某個代理啟用強制執行，讓未列出的目標被拒絕。nettop 取樣器可以回報違規，但無法封鎖連線。

它能辨識哪些代理？

Claude Code、Codex、Cursor、Windsurf、GitHub Copilot、Gemini CLI、Aider、Goose、OpenCode、Ollama、LM Studio、 ChatGPT、Claude、Zed、Perplexity 和 ZCode，以及任何呼叫已知 LLM API 的非瀏覽器程序。要再加一個， 只需要一行的 pull request。

它怎麼更新？

Flowlight 每天向 GitHub 查詢一次最新版本。有新版時，它會顯示發行說明，也可以下載 磁碟映像檔、用公布的 SHA-256 驗證後開啟。你可以在「設定」中關閉這項檢查。

真的完全免費嗎？

是。它是依 GPL-3.0 授權的自由軟體：沒有付費方案，也不收集資料。
