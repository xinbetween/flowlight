Every app. Every domain. Every agent.

Flowlight shows which app on your Mac talked to which domain, over which protocol, and how much it sent. It keeps a closer eye on AI agents, so an email, an SSH session or a 180 MB upload you never asked for doesn't go unnoticed. Turn on HTTPS inspection and you see the tool calls behind it, too.

⚠ Critical

Allowlist violation

"Claude Code may talk to GitHub and npm, nothing else." Add domains, IPs or ranges, or start from a preset. Anything else raises an alert, with one-click Allow — and, when you ask it to, the Network Extension refuses the connection instead of only reporting it.

Claude Code › curl contacted paste.example:443, which isn't on Claude Code's allowlist

⛔ Refuses

Rules, for as long as you say

Name an app, an agent, a destination or a single URL and block it — right-click the row you spotted it in. Forever, until a time, until Flowlight quits, or between chosen hours, with one pause switch and a way out on every refusal. The most specific rule wins, and a tie goes to the block.

Cursor ⇥ raw.githubusercontent.com · refused 4 times · weekdays 18:00–09:00

⛔ Refuses

Guardrails on an agent's tools

Block an MCP server, one of its tools, or one resource. A refused tool is removed from the list the agent sends its model, so the model is never offered it — no refusal to argue with, no retry loop. It needs HTTPS inspection, and it is not a sandbox: Flowlight says so rather than implying otherwise.

Why Flowlight exists

Your tools now make their own decisions. You should be able to see where your data goes when they do.

Coding agents read your files, run commands and call tools, and any of those tools can open a socket. In September 2026, an AI coding app was found packaging users' whole workspaces, Git history included, and uploading them in the background. The researcher who caught it only noticed because a cache folder was eating disk space.

The uploads were encrypted, but the facts that mattered weren't: which app, which host, how many megabytes, and when. macOS already knows all of that. Flowlight puts it on screen, keeps the history, and flags what doesn't look right.

HTTPS inspection · optional

See the tool call behind every request

Off by default. Turn it on and Flowlight becomes a local proxy with its own certificate authority, created on your Mac. Start an agent from an inspected Terminal and every request it and its tools make is decrypted, with the tool calls the model asked for and the results that went back.

Tool calls and results

Anthropic, OpenAI, Gemini and MCP. Each call with its command, its output or error, and the requests its tool made.

Models and tokens

Which model answered, how many calls, and tokens in, out and served from cache, per agent.

Readable bodies

JSON as a collapsible tree in its original order, streams one event at a time, headers and raw view.

On your terms

AI agents only by default. Apple services and password managers are never decrypted, credentials never stored, and one button removes it all.

Privacy

A monitor you don't have to monitor

Stays on your Mac

One local SQLite file. No account, no cloud sync, no telemetry.

Metadata by default

Hostnames, ports and byte counts. Decrypting HTTPS is a separate mode you have to turn on, and it stays on your Mac.

Filtered in the kernel

Lookups you control

FAQ

Questions

Does Flowlight block traffic?

By default it watches and alerts, including when an agent leaves its allowlist. It can also refuse those connections, but only for an agent you have turned that on for, and only with the Network Extension engine installed — the sampler can only watch. Local traffic, DNS, Apple services and Flowlight's own connections are never refused.

Can it read my HTTPS traffic?

Not by default. It reads the hostname a client asks for when it opens a connection (TLS SNI) and the DNS answers that map names to addresses, and contents stay encrypted. If you want the full picture, HTTPS inspection is a separate, opt-in mode: Flowlight becomes a local proxy with its own certificate authority and decrypts the apps you route through it (AI agents only, by default), including every tool call a model asks an agent to run. Apps that pin their certificates still refuse it, and Apple services and password managers are never decrypted.

How is this different from Little Snitch or LuLu?

Those are firewalls that ask you to allow connections. Flowlight is an analytics tool: history at any zoom, anomaly baselines, and rules built for AI agents. They work well side by side.

Why does it ask for my password?

macOS only lets administrators read network packets. The one-time setup gives your account read access, the same way Wireshark does. You can remove it any time from the Capture screen.

Can it tell which MCP server or tool made a request?

Yes, at the process level. Flowlight follows each process back to the agent that started it, so a shell tool's curl or an MCP server's connections are attributed to that agent, and MCP servers are named from Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Codex, Zed and Gemini CLI configs. It can't see which individual tool call inside a long-running server opened a connection.

Does an allowlist block traffic?

Not yet. A violation raises a critical alert and marks the destination "Not allowed". Blocking needs the Network Extension engine and is on the roadmap.

Which agents does it recognize?

Claude Code, Codex, Cursor, Windsurf, GitHub Copilot, Gemini CLI, Aider, Goose, OpenCode, Ollama, LM Studio, ChatGPT, Claude, Zed, Perplexity and ZCode, plus any non-browser process that calls a known LLM API. Adding one is a one-line pull request.

How does it update?

Once a day Flowlight asks GitHub for the latest release. When there's one, it shows the notes and can download the disk image, verify it against the published SHA-256 and open it. You can turn the check off in Settings.

Is it really free?

Yes. It's free software under the GPL-3.0: no paid tier, no data collection.
