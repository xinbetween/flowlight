개인정보

기본은 로컬, 예외는 모두 문서로

Flowlight는 계정이 필요 없고 제품 분석 기능도 없습니다. 트래픽 기록은 Mac 안에 저장됩니다. 이 페이지는 앱이 무엇을 기록하는지, 외부 서비스에 접속하는 선택 기능은 무엇인지, 그리고 이 설명을 소스 코드에서 어떻게 확인할 수 있는지 밝힙니다.

이 페이지 안에서 요약기록하는 것패킷 캡처Mac에서 읽는 것HTTPS 검사 네트워크 요청권한보관 기간 이 웹사이트문의

요약

  • Flowlight는 네트워크 메타데이터(어떤 앱이, 어떤 호스트로, 어떤 포트로, 몇 바이트를, 언제)를 Mac 안의 데이터베이스에 기록합니다.
  • 패킷 내용은 절대 기록하지 않고 트래픽을 복호화하지도 않습니다. 선택 사항인 HTTPS 검사를 켜고 앱을 그리로 보낸 경우만 예외입니다.
  • Flowlight는 트래픽 데이터베이스를 업로드하지 않으며, 텔레메트리와 크래시 보고, 제품 분석 기능이 없습니다.
  • 앱 자신이 내는 외부 요청과 사용자가 설정한 내보내기 경로는 아래에 정리해 두었습니다.

기록하는 것

1초마다 앱(번들 ID, 이름, 실행 파일 경로, 프로세스 ID)과 원격 IP 주소, 호스트 이름, 포트, 전송 방식과 프로토콜, 그리고 보내고 받은 바이트 수를 기록합니다. 띄운 알림과 이상 탐지 규칙이 쓰는 앱별 기준선도 저장합니다. 전부 ~/Library/Application Support/Flowlight에 있습니다.

패킷 캡처

한 번만 하는 호스트 이름 설정을 승인하면, Flowlight는 기본 네트워크 인터페이스의 패킷을 커널 필터를 통해 읽습니다. 이 필터는 두 가지만 통과시킵니다. DNS 응답, 그리고 TLS 연결의 첫 메시지(ClientHello)입니다. 거기에서 호스트 이름과 그것이 가리키는 주소만 메모리에 보관합니다. 나머지는 커널에서 버려지며, 어떤 패킷도 디스크에 쓰이지 않습니다.

Mac에서 읽는 것

에이전트의 도구와 MCP 서버를 귀속시키기 위해, Flowlight는 macOS에서 각 프로세스의 부모와 명령줄을 읽고, 지원하는 에이전트의 MCP 설정 파일(예를 들어 ~/.claude.json, ~/.cursor/mcp.json, ~/.codex/config.toml)을 읽습니다. 각 서버의 이름과 실행 명령, URL만 메모리에 보관하고, 트래픽과 함께 저장하는 것은 그 결과로 붙는 표시(“curl 경유”, “github MCP”)뿐입니다. 이 파일이나 명령줄의 내용은 어디로도 보내지 않습니다.

HTTPS 검사

기본값은 끔입니다. 켜면 Flowlight가 Mac 안에 인증 기관을 만들고(그 키는 ~/Library/Application Support/Flowlight/Inspection를 벗어나지 않습니다) 이 Mac에서 오는 연결만 받는 프록시를 돌립니다. 이 프록시를 거치도록 지정한 앱에 대해서는 요청과 응답을, 최대 2 MB까지의 본문을 포함해 로컬 데이터베이스에 3일 동안 기록합니다. 인증 정보 헤더(Authorization, 쿠키, API 키)는 저장 전에 그 길이 값으로 대체됩니다. Flowlight는 내장된 Apple 서비스와 암호 관리자 목록을 복호화에서 제외합니다. 기록된 검사 데이터를 Flowlight가 업로드하는 일은 없습니다. 검사를 끄면 프록시가 멈추고, 인증서 및 기록된 데이터 제거는 인증서와 그 신뢰 설정, 기록된 모든 요청을 삭제합니다.

보관 기간

초 단위 데이터는 6시간(조절 가능), 분 단위는 14일, 시간 단위는 400일, 일 단위 합계는 무기한, 알림은 90일입니다. 캡처 › 모든 데이터 지우기가 전부 삭제하며, ~/Library/Application Support/Flowlight를 지워도 같습니다.

이 웹사이트

이 사이트는 GitHub Pages에 올려 Cloudflare를 통해 제공하는 정적 페이지입니다. 쿠키를 설정하지 않고 분석 도구도 돌리지 않습니다. 페이지를 전달하기 위해 GitHub와 Cloudflare가 요청을 처리하며, 폰트는 Google Fonts에서 불러오므로 방문 시 그곳이 IP 주소를 받게 됩니다.
